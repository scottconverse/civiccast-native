## What it is for
The channel control page. It shows each outgoing channel (its identity, what is playing now/next, the schedule, the proof log) and holds the controls that put a channel on the air or take it off: Start/Stop/Restart/Finish-then-stop for the outgoing feed, "Commit programs to air", "Live takeover", cable headend settings, 24/7 automation, a lower-third banner, and public app branding. Several of these controls change what residents and cable subscribers see right now.

## What the user sees
`ChannelOpsScreen.tsx:1967-2111`, top to bottom:
1. Heading "Channels", text "Monitor linear channel identity, current playout, fallback behavior, proof logs, and CTV feed readiness." and a pill "refreshes every 30s" (1971-1982). Red "Channel status could not load." + API message when any of the screen's queries fails (141-152).
2. "Channel lineup": one card per channel with a coloured logo box, display name, "<kind> / <channel_id>" and the channel's fallback text; click selects it (154-196). First channel is selected by default (1757-1760).
3. Left column: "Station app config", "Now / next", "Commit programs to air", "Playout plan", "Proof log".
4. Right column: "Channel branding", "Outgoing channel feed", "Live takeover", "Cable verification", "Loudness", "Captions", "Audio tracks (SAP / descriptive)", "Cable headend delivery", "Run this channel 24/7", "Lower-third banner", "Software outputs", "Reference CTV feed".
5. One shared confirmation dialog (2097-2109) used by feed commands and headend presets.

## Typical task flows (only what the code supports)
1. Start a channel for a meeting: confirm an outgoing-feed configuration exists (apply a preset if not) -> "Start" -> confirm "Start feed" -> watch the pill change to Starting then On air (poll every 2 s for 20 s).
2. Go live from a camera: on Live, "Check source" until "Delivering" -> here "Take live" -> "Confirm take live" -> later "Return to schedule" -> "Confirm return to schedule".
3. Put a scheduled program on air: "Review & prepare" -> read "Safe to air" -> "Approve & put on air". To undo: "Take off air" + reason + "Confirm take-off".
4. Stop: "Stop" or "Finish current item, then stop" -> confirm.
5. Banner: type text -> "Put on air" -> "Confirm: put on air" -> restart/swap for it to appear.
6. Setup admin: choose a cable preset, paste destination, "Apply headend preset" and confirm; "Verify stream (TSDuck)".
