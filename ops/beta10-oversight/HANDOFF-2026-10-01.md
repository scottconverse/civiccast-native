## 7. Running and watching a rung

- **Start only when all 3 channels are on air** (check `bin\channel-state.ps1` / the control-plane log for
  `egress state -> ON_AIR` on each) — starting early cost C15 a failure.
- Start (background): `cd <oversight> && powershell.exe -NoProfile -ExecutionPolicy Bypass -File bin/rung.ps1 -Name <name> -Minutes 480`.
  It starts `segment_keeper.py`, runs verify every ~11 min and a 240 s loudness capture every ~30 min, adjudicates
  loudness FAILs, and writes `rung.log` + evidence. At the end it kills keepers matching its KeepDir. To end a rung
  early, kill both the rung.ps1 PowerShell process and its keepers.
- **Watches** (Monitor tool; each expires at 30 min, so renew every ~25 min with a background `sleep 1500` alarm,
  overlapping old and new):
  - program changes: `cd <oversight>/bin && python -u changeover_hole_watch.py 1740 2>&1 | tee -a ../evidence/changeover-holes.log`
    (the log holds older days too — filter by today's segments);
  - faults: `sed 's/forcing switch"/forcing switch|dropped future-dated"/' <oversight>/bin/monitors/detector-monitor.sh | bash`;
  - schedule slips: `bash <oversight>/bin/monitors/schedule-monitor.sh`;
  - station events: `bash <oversight>/bin/monitors/station-monitor.sh`;
  - rung log: tail the newest `evidence/rung-<name>-*/rung.log`;
  - disk: warn < 15 GB, alarm < 10 GB (`df -BG /c`);
  - problems: grep the control-plane log for `aborted|did not land|discarded:|resolved to a [0-9.]+s tail|target=filler|FALLBACK_SLATE|misses the loudness gate|leveling ride failed|catch-up .*Discarded`.
  - 10-min clock: `for i in 1 2; do sleep 600; echo "10-min check #$i"; done; sleep 540; echo "30-min REPORT due"`.
  Give every loop its own deadline (expired Monitors otherwise leave orphan bash loops).
- **Reading results:**
  - `verify BAD caption_decode_back=FAIL(no positive worker receipt ...)` → check the channel's VTT
    (`C:\ProgramData\CivicCast\data\egress\<ch>\captions\*.vtt`, newest) for a recess ("five minute break" … "break
    is over"); save the cue excerpt to evidence. `CAPTION_QUIET` = OK with a note.
  - loudness FAIL → do **not** trust the adjudicator's `position.source = "log"` on a channel that has aired the same
    asset across several parts. Re-adjudicate with the station python and `--position <ch>=<source seconds>`; find
    the source offset by correlation and confirm by measuring the source at idle priority. Two shared loudness facts:
    ride max lift 18 dB, so the reach floor is −35 LUFS.
  - changeover lines: CLEAN/HOLE, `video_max`, `audio_max`, `relay_invalid_ts_new` (>0 = audio lost).
  - "dropped future-dated video arrival ... ahead≈piece length" = known piece-join single-frame drop (backlog).
- **Verdict:** write `VERDICT-NOTE.md` in the evidence folder (raw verdict, each failure adjudicated with evidence,
  gate totals, known limits, coordinator slips), log it, then report.
