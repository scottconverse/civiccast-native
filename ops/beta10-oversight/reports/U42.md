## 30. Doubts

* **The fix is a correction on a measurement that has no error bar.** `measure_artifact` returns one
  integrated number; the pad round now corrects its drive by that number once, with no second pass, by
  design ("At most one correction"). On cell A the correction was −0.60 dB and it landed 0.16 LU inside a
  0.5 LU tolerance; a 0.16 LU error bar is not obviously larger than the measurement's own noise. If the
  next window's correction over-shoots, the same 0.03 LU coin-flip from Part IV's §20 decides again which
  attempt ships — but now it decides between two *lawful* attempts rather than between lawful and
  over-bound, which is the real improvement here.
* **The guard now stops earlier.** Cells A and B end at the pad round; the variant fallback that HEAD
  spent on A (three extra encodes) no longer runs there. That is answer-2's design and it is faster, but
  it means the pad round's single correction is the whole of the guard's response on exactly the cells
  where it barely wins.
* **One product behaviour changed that nobody asked about, and it is disclosed, not hidden:**
  `guard_pad_trim_db` is *also* the same correction the nominal path uses ("same code path if it exists
  (reuse, do not duplicate)" — the work order). If that shared path is wrong, it is wrong in two places.
* **The cell-A ship is a bigger change than "fixes an overshoot" sounds.** The artifact residents get goes
  from a 3.2 dB-hot nominal at a 256k fast-coder profile to a 192k profile at a −4.75 dBTP ceiling with a
  +2.95 dB drive. Both are inside the gates; they are not the same product. I have no listening evidence
  for either and I did not ask anyone to listen.
* **The two extras in §25 are inferences.** The cea708 node is *not proven* to be independent of U43 — it
  is argued independent from blast radius and from the skip in isolation, against a differential that
  structurally cannot test it. If someone wants that closed, the measurement is a base-revision full suite
  (~48 min) or a full suite in a tree where `gi` is present for both revisions — neither of which this
  carry ran.
* **The station is running right now.** Every number in this Part was taken while the live air path was
  encoding on the same box. I kept to one encoder at a time and BELOW_NORMAL as the brief requires, but
  "the sweep passed" is a statement about a shared machine, not about an idle one.
