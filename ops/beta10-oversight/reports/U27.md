### Two premises in the brief that are probe artifacts, not defects

Both are `ffprobe stream.duration` accounting on AAC-in-MPEG-TS: it counts whole AAC
frames (`N × 1024 / 48000`) and drops the tail frames. It is not the audio on the wire,
and the watchdog does not use it (it reads first-packet PTS).

- *"30.000 s video / 29.76 s audio"* on the slate file:
  ```
  index=0 codec_type=video duration=30.000000 nb_read_packets=900
  index=1 codec_type=audio duration=29.760000 nb_read_packets=1407
  ```
  but the actual audio packets span 1.400000 .. 31.394667 = **29.994667 s** (29.76 =
  1395 × 1024/48000). Real spans agree to 33 ms. (`slate-source-facts.txt`)
- *"audio output is only 1.8346 s per 2 s segment"*: `seg000000100.ts` reports
  `duration=1.834667` (86 × 1024/48000) while its 94 audio packets span
  202.587978 .. 204.571978 = **1.984 s**, against 60 video packets spanning
  202.579978 .. 204.546644 = 1.967 s. (`ffprobe-duration-artifact.txt`)

## 4. Fix (option b)

Committed as `4da5b68b` (tests) then `af2162c7` (source); `6b1c218c` (docs) then
records it in `CHANGELOG.md`. Diffstat vs `8e9c2ed7`: the code commits are 6 files,

`SlateSourceGenerator` now emits **one** segment spanning the whole fill horizon, whose
path is a single stream-copied file (post-fix `civiccast/egress/source_plan.py`):

```
:206  repeats = max(1, -(-self._target_fill_seconds // self._duration_seconds))
:207  fill_seconds = repeats * self._duration_seconds
:208-222  segment = EgressSourceSegment(... path = output_path if repeats == 1 else self._render_fill(...),
                                          duration_seconds=fill_seconds ...)
:225  segments=[segment]
:228  def _render_fill(...)          # N "file '<path>'" manifest lines -> ffmpeg -f concat -safe 0 -i M -c copy staging -> staging.replace(fill)
:277  def _fill_cache_key(...)       # keyed on the slate cache key, the fill length, the source size
:681  def _escape_concat_path(...)   # moved here as the single shared implementation
```
