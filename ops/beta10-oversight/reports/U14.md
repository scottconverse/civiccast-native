### 8.2 What the restart does now (OBSERVED, all `daemon.py`)

1. `_reload_steps` declines the seamless arm for exactly one combination — `not
   request.switch_at_end_of_current` **and** the channel's current state is `FALLBACK_SLATE`
   (`3953-3962`) — and returns `_ReusePreparedPlan(preparation_report, target_state)` (`3962`)
   instead of arming. If no preparer is configured (`preparation_report is None`) it returns `False`
   and the ordinary decline path runs unchanged.
2. `_ReusePreparedPlan` (`386`) carries the report **and** the `target_state` the seamless path would
   have published, so a force-fallback filler rollover comes back up as `FALLBACK_SLATE` rather than
   `ON_AIR`.
3. `_poll_preparation` routes that outcome to `_fall_back_to_restart_for_reused_plan` (`967-972` →
   `3680`), which stashes the carrier and calls the existing `_fall_back_to_restart_reload(channel,
   prepared_reload=...)` (`3692`); the synchronous preparation path is handled identically in
   `_try_content_reload` (`3716-3723`).
4. `_fall_back_to_restart_reload` (`4289`, `prepared_reload: _ReusePreparedPlan | None = None`) stashes
   the plan (`4315`) and otherwise runs byte-for-byte as before.
5. `_start_steps` pre-assigns `resolved_plan = prepared_reload.report.source_plan` (`1572`) so the
   provider is never consulted a second time and the "no valid source plan available" aborts are
   unreachable, then, on the non-slate branch, binds the report's plan **and** `plan_dir` without
   yielding to the preparer (`1795-1819`), and logs
   `"Restarting %s onto the plan its interrupted reload already prepared: label=%r plan_dir=%s
   state=%s."` (`1816`).
6. The state row shows the report's source label — option (a): `resolved_plan` is the report's plan
   (`1572`), the resolution consumes it at `1713-1714`, and the STARTING row therefore carries
   `source_plan.segments[0].label` from it (`1767-1772`). A reused plan that resolves as a slate
   writes no STARTING row at all and keeps the `FALLBACK_SLATE` row (`1700`/`1710`); the
   filler-rollover test asserts exactly that row — `state.state == "FALLBACK_SLATE"` **and**
   `state.current_source_label == "Fallback slate"`.
7. The stashed `plan_dir` is in `live_prepared_plan_dirs` while the restart is in flight (`3604-3617`,
   the preparer's GC `keep=` set), and released on every path that does not consume it: a newer
   preparation (`1501`), a start failing before the plan is bound (`1530`), a live worker already
