- **Base = the live station's own bytes.** Every one of the nine base files was re-read from

  time; no hash was copied from a report. `proof5` re-reads them again and reports
  `live and staged base agree with the recorded hash for all nine: True`.
- **The carry is the range delta re-expressed on the live bytes.** Per file,
  `patches/range/<file>.patch` is the diff from the live base to the candidate; `patches/carried/`
  holds the `8e9c2ed7..HEAD` reference diff; `patches/live-drift/` holds the station's own drift for the

  removed. U24's 58 MB / 2780-file side trees are deliberately not reproduced. Hardlink-cloning was
  rejected: a write through a hardlink would edit the live station in place, which the brief forbids.
- **The side roots are not a package subset.** Proof 3 runs HEAD's whole `tests/` tree
