## 9. Findings and doubts

1. **`gsthlssink3.dll` licence disagrees with the shipped licence table.** OBSERVED: a live
   `gst-inspect-1.0` probe reports `License=MPL`, `Source module=gst-plugin-hlssink3`, where
   `civiccast/native/runtime_licenses.py`'s table records `LGPL-2.1-or-later`. The identical probe
   on the installed 1.28.5 tree gives the identical answer, so this **predates** the update
   (INFERRED: it is a wrong entry in the table, not a 1.28.7 change). The table value was
   deliberately left unchanged — it feeds the shipped per-file licence table, and licence posture is
   an owner-acceptance item. Recorded in the CHANGELOG and in a dated comment in
   `runtime_licenses.py`; flagged here for the coordinator's decision. No refusal fired.
2. **The live-engine suite is flaky on this machine** (§8.3). Any acceptance run that leans on
   `tests/egress/test_gst_engine_wsl.py` should report the failure *set*, not the count, and should
   not run two runtime-gated suites concurrently.
3. **`__pycache__` in the staged tree breaks a second verifier run.** OBSERVED: my own scratch GI
   probe (`%TEMP%\u17\giprobe.py`, which imports the tree's `gi` with the tree's Python) wrote 16
   `.pyc` files into `staging\U17\gstreamer\python\gi\*\__pycache__`, after which the verifier's
   `manifest_verification` correctly refused the tree (`ORPHAN (on disk, absent from manifest)`,
   6 PASS / 1 FAIL) because the manifest lists 224 files and `SHA256SUMS`/the manifest contain no
   `pycache` entry. I removed those 16 files (they were mine, not build output) and re-ran: 7 PASS /
   0 FAIL. The verifier itself is not at fault — it sets `PYTHONDONTWRITEBYTECODE=1` for its
   children. Practical consequence for the coordinator: **verify the tree before importing anything
   from it**, and re-verify after a rebuild rather than after a test run.
4. **Docs still naming 1.28.5** (§3.2c) — listed, not changed. The one I would most want a
   decision on is `docs/design/spec-packaging-closure.md:13-14`, because it reads as a statement
   about the current closure input rather than as history. `docs/claims/claims.yaml:636,1397`
   should be updated only together with the evidence it describes.
5. **Environment-variable spelling trap.** The product's variable is
   `CIVICCAST_GSTREAMER_RUNTIME_ROOT` (CIVIC-**CAST**, matching the product name; the packaged
   Python path key is `CIVICCAST_GSTREAMER_PYTHON`). Early in this unit I exported
   `CIVICAST_GSTREAMER_RUNTIME_ROOT` (one C short) — the gate then **skips silently** rather than
   erroring, so a whole runtime-gated run reports "28 skipped" and looks like an environment
