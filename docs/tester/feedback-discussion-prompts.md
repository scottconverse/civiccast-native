# Feedback Discussion Prompts

Use these prompts to seed tester feedback threads.

## First Install

- What was the first step that made you hesitate?
- Did the installer language feel understandable?
- Did the handoff to the operator console happen when you expected?

## First Admin And Recovery

- Did the recovery kit feel important without feeling scary?
- Did you know where to store it?
- Would someone else at your organization understand it?

## Safe To Broadcast

- Did Ready, Check first, and Do not broadcast yet make sense?
- Did yellow items explain whether you could still proceed?
- Did resident preview increase confidence?

## Meeting Source

- Which source option matched your real equipment?
- Were any acronyms confusing?
- Did sample upload help you test without a camera?

## Support

- Was the support bundle easy to create?
- Did the bug report template ask for the right information?
- What question did the FAQ fail to answer?
