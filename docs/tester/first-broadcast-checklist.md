# First Broadcast Checklist

Use this before the first real meeting and after major setup changes.

## Setup

- [ ] Installer finished without a red required lane.
- [ ] Operator console opened from installer handoff.
- [ ] First admin exists.
- [ ] Recovery kit was saved or printed.
- [ ] Backup destination verifies.
- [ ] The database restore drill passed, and separate media/configuration/
  credential recovery procedures are recorded.
- [ ] System Health required checks are not red.
- [ ] If a supported server-side media probe is configured, a private
  rehearsal ran. Otherwise, the system failed closed and no real meeting is
  approved.

## On-Air Approval

- [ ] Every manually-added program for this broadcast has been **Committed to
  Air** in Channel Ops (a *scheduled* item that is not committed will not air —
  it falls to slate). Auto-schedule rule items are approved when the rule is
  compiled and need no separate commit.
- [ ] The public "Coming Up" schedule lists the programs you expect (only
  committed items appear there).

## Source

- [ ] Meeting is selected or test upload is ready.
- [ ] Camera, encoder, phone app, NDI source, or uploaded file is selected.
- [ ] Preflight sees video and audio.
- [ ] Unverified source media shows **Source preview unavailable** and blocks
  live start; no simulated preview or source-drop control is present.

## Resident View

- [ ] Resident preview opens.
- [ ] Public portal shows the expected station/meeting state.
- [ ] Test playback works from another browser.

## Review And Publish

- [ ] Captions are reviewed or station policy allows auto-generated captions.
- [ ] Summary claims are sourced or held for later review.
- [ ] Required publish/archive surfaces are ready.
- [ ] Optional providers are not treated as required unless station policy says
  so.
- [ ] Support bundle can be generated if anything fails.
