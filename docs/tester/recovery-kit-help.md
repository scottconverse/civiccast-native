# Recovery Kit Help

Use this page if you closed the recovery kit screen, lost the recovery code, or
are not sure what the recovery kit is for.

## What The Recovery Kit Is

The recovery kit is the emergency access information for your CivicCast
station. It helps you recover the station if the first admin password is lost
or if support needs to prove that you control the station.

Treat it like a password. Do not paste it into bug reports, support bundles,
chat messages, screenshots, or public issue trackers.

## What To Do During First Setup

When CivicCast shows the recovery kit:

1. Save it somewhere private.
2. Print it if your organization stores paper emergency credentials.
3. Give access only to people who are allowed to administer the station.
4. Confirm that you saved it before moving on.

Good storage places include an organization password manager, a locked office
file, or another approved credential vault.

Bad storage places include email, public chat, shared screenshots, issue
trackers, or documents that many people can open.

## If You Closed The Tab Before Saving It

Do this first:

**If the operator console is already open in another browser tab:**

1. Go back to Setup.
2. Look for the first admin or recovery-kit step.
3. If CivicCast still shows the recovery kit, save or print it before doing
   anything else.

**If the operator console is closed:**

1. Reopen the CivicCast operator console from the installer handoff link if it
   is still visible.
2. Look for the first admin or recovery-kit step.
3. If CivicCast still shows the recovery kit, save or print it before doing
   anything else.

If the recovery kit is no longer visible, do not guess and do not share private
station files. Create a support bundle and report that the recovery kit was
closed before it was saved.

## If You Lost The Recovery Code

If the station is still accessible with an admin account:

1. Sign in as an admin.
2. Create a support bundle.
3. Ask the station owner or technical contact to rotate or replace recovery
   credentials according to your organization's policy.

If no admin can sign in:

1. Stop using the station for real meeting records until access is recovered.
2. Contact the person who installed CivicCast or your station support contact.
3. Provide the support bundle if you can create one without exposing secrets.
4. Do not post recovery codes, passwords, database files, private keys, or
   provider credentials in public.

## If A Tester Needs To Report This

Use this wording in the tester report:

> I closed or lost the recovery kit before saving it. I did not paste recovery
> codes or secrets into this report.

Then include:

- Whether the operator console still opens.
- Whether an admin can still sign in.
- Whether a support bundle was created.
- The screen where the tester got stuck.

## What CivicCast Support Needs

Support needs the symptom, not the secret.

Safe to include:

- CivicCast version.
- Operating system.
- Screenshot with recovery codes hidden.
- Support bundle generated by CivicCast.
- What the tester clicked before the recovery kit disappeared.

Do not include:

- Recovery codes.
- Passwords.
- Provider credentials.
- Private keys.
- Subscriber data.
