# CivicCast Steering Committee Bridge

Status: v1.0 interim bridge.

Date: 2026-05-15

## Current Composition

The formal CivicCast Steering Committee is not seated yet.

For v1.0 readiness, the project uses this interim governance bridge:

| Role | Current holder | Scope |
| --- | --- | --- |
| Interim project maintainer | Scott Converse | Release authority, final scope decisions, merge/release approval |
| Implementation agent | Codex | Implements scoped changes and records local evidence |
| Audit counterpart | Claude / independent audit pass | Reviews release evidence and challenges drift before final release |

## v1.0 Commitment

The v1.0 release may proceed under this bridge if the go/no-go document records:

- no unresolved Blocker/Critical readiness findings; or
- explicit deferral of any unresolved item to a named release path with Scott's
  approval.

## Post-v1.0 Committee Formation

After v1.0, the maintainer should recruit three to five committee members
covering:

- public meeting operators;
- community media operators;
- accessibility/privacy review;
- project maintenance and release engineering.

The first seated committee should ratify or replace
`docs/governance/bylaws-draft.md`.
