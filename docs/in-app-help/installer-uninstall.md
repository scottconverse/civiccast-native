## What really happens
Uninstall first checks whether the older CivicCast edition that ran inside Windows Subsystem for Linux is also installed; if so it asks whether to hand it the job of running the station (Hooks:1845-1892). It then stops and removes the CivicCast service, deletes the firewall rule and clears the registry entries, including the stored database password; if that does not finish, it stops with exit 82 and removes nothing (Hooks:1933-2006). Then it deletes the program files, the model packs and the whole install folder, and the three shortcuts (Hooks:2209-2214, 2328-2331). It never touches `C:\ProgramData\CivicCast`, where the database, recordings, uploads, logs and anything the first-run window downloaded stay (Hooks:2307-2312). The model-pack cache inside the install folder (about 21 GB) is deleted, which is why a later reinstall needs the full kit (audit item MA-17, Hooks:2188-2209).

## Proposed text
Ownership box (replace Hooks:1850; Yes/No): "CivicCast (Native) is currently set to run this computer's channels, and an older CivicCast edition (the one that ran inside Windows Subsystem for Linux; Settings, Apps lists it as 'CivicCast Installer') is also still installed. To remove CivicCast (Native), the job of running the station must first be handed to that older edition. After that, the older edition is the one that starts and sends channels. Hand it over now and continue removing CivicCast (Native)? Choose No to cancel; nothing is removed." List lines: "Checking whether the older CivicCast edition is installed..." (Hooks:1845); after No: "Uninstall cancelled (setup exit 130). You chose not to hand the station to the older edition. Nothing was removed."

Teardown refusal, exit 82 (replace Hooks:1986): "Setup error 82. CivicCast (Native) could not be uninstalled, so the uninstall was stopped and NOTHING was removed. Your installation is still complete and can be uninstalled again. The step that stops and removes the CivicCast service, removes the firewall rule and clears registry entries returned code N. Most often the CivicCast service did not stop. To fix: press the Windows key and R, type services.msc, press Enter, find 'CivicCast Native Supervisor', choose Stop (or restart Windows), then run Uninstall again. (Administrator command prompt: sc stop CivicCastSupervisor.) Details: C:\ProgramData\CivicCast\install-progress.log." Use the same service wording at Hooks:2067 and drop "database/messaging" ("its database and AI processes").

Model-pack notice (replace Hooks:2209, keep the substrings "are NOT affected", "full CivicCast kit folder" and ".station-cache"): "CivicCast (Native) is being removed, including the speech and AI model packs (about 21 GB) kept in <install dir>\packs\.station-cache. Your recordings, database and settings in C:\ProgramData\CivicCast are NOT affected and are being kept. If you reinstall later, setup.exe on its own cannot fetch the model packs again: reinstall from the full CivicCast kit folder (setup.exe together with its 'packs' and 'station' folders). To reinstall without the kit, copy <install dir>\packs\.station-cache to a safe place before you choose OK."
After fix: show this as an OK/Cancel box in `NSIS_HOOK_PREUNINSTALL` before the teardown (Hooks:1933), so Cancel really cancels.

What uninstall keeps (in-app help, now): "Uninstall removes CivicCast (Native) from C:\Program Files\CivicCast (Native) (or the folder you chose), its Windows service, firewall rule and shortcuts. It keeps C:\ProgramData\CivicCast: the database (data\pgdata), recordings and uploads (data\uploads), the ready-to-play cache and working files (data\egress), logs, and any packs the first-run window downloaded. It also keeps %USERPROFILE%\.civiccast, the setup window's notes about itself. Uninstall never deletes that data. To wipe the computer, back up what you need first, then delete C:\ProgramData\CivicCast yourself; that permanently destroys the database, recordings and settings."

Checkbox (needs Lang edit, Lang:58): "Also delete the setup window's saved settings for this Windows account. If you leave this unticked, the first-run download screens will not appear again after a reinstall on this account. Your recordings, database and settings in C:\ProgramData\CivicCast always stay on this computer."
