## What really happens
The upgrade engine runs on every install and decides from the Windows service list whether this is a fresh install (exit 11), the same version (12), a downgrade (13) or an upgrade; an upgrade backs up, migrates and health-checks the database and rolls back on failure (Hooks:1035-1050, 1135-1285). Then the database step creates the PostgreSQL data folder under `C:\ProgramData\CivicCast\data\pgdata` and stores the connection string in the registry, or reuses an existing one (Hooks:1291-1301). By the time either step can fail, setup has already replaced the program files with the version being installed, so every failure here also stops the service and sets it to manual start (Hooks:335-344, 384-419). Nothing in these steps touches recordings.
