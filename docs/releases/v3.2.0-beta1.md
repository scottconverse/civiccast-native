# CivicCast v3.2.0-beta1 Release Notes

Release date: 2026-07-02

`v3.2.0-beta1` is the CivicCast 3.2 beta release for controlled station
testing. It includes the CivicCast 3.0 GStreamer station-in-a-box base plus
the 3.2 control-room and virtual media studio work for the Longmont Public
Media lab profiles.

## Download

Use the GitHub release:

`https://github.com/scottconverse/civiccast/releases/tag/v3.2.0-beta1`

Primary Windows installer asset:

`civiccast-3.2.0-beta1-windows-setup.exe`

Verify the installer hash and byte size against the GitHub release page and
the matching `civiccast-3.2.0-beta1-release-artifacts-manifest.json` asset
before running it.

## What's Included

- CivicCast runtime and Windows installer version stamped as `3.2.0-beta1`.
- Control-room device inventory, cue, mode-gate, audit, and support-bundle
  surfaces.
- vMix HTTP, OBS WebSocket, ATEM, VISCA/PTZ, DeckLink, NDI, generic USB
  capture, Castr, and YouTube contract-lab coverage where software interfaces
  are available.
- Virtual media studio scenarios for fixed-studio livestreaming, portable
  field kit, and digitization/OBS profiles.
- Release-gate evidence for Lite, Walkthrough, and Full GauntletGate lanes.
- 4-hour elapsed local contract-lab soak evidence.
