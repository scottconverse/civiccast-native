Status: SUPERSEDED — historical proof map from the pre-reset "v1.7" numbering. The current release line is v1.0.0-rc1 (see docs/releases/v1.0.0-rc1-verification.md).

This page gathers the evidence an early adopter should read before deciding
whether CivicCast is ready for a controlled trial. It is a proof map, not a
claim that every future deployment path is complete.

- v1.5.0: resilience beta for restore, update, rollback, and quality gates.
- v1.6.0: channel and CTV beta for software-owned channel planning, monitoring,
  proof logs, and public feed contracts.

## Known Boundaries

- v1.7 does not claim Roku Channel Store publication or certification.
- v1.7 does not claim SDI, DeckLink, Comcast, or physical headend delivery
  proof.
- v1.7 does not claim DRM readiness or streaming-TV platform certification.
- v1.7 does not certify accessibility, records retention, procurement
  compliance, or legal compliance.
- Packaged Windows installer claims require exact GitHub Release asset checksum
  and smoke proof for that asset.

## Early-Adopter Decision Rule

A station should treat CivicCast v1.7 as ready for a controlled early-adopter
trial when:

1. The station can install from GitHub Releases and verify the checksum.
2. System Health reaches **Ready** for the selected rehearsal path.
3. Backup and restore rehearsal pass.
4. A short test recording or live rehearsal publishes to the resident portal.
5. Support intake and security-reporting paths are understood.
6. Any unproven provider, hardware, or platform path is explicitly outside the
   station's first trial.
