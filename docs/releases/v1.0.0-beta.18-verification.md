# CivicCast v1.0.0-beta.18 package verification

Beta 18 adds a Setup-admin Cablecast station-import screen to the existing
metadata importer. Operators can enter a source connection, preview proposed
shows and schedule entries with conflicts and skipped records, explicitly apply
the plan, inspect the resulting batch, and confirm rollback. This release does
not copy media files. The other open Sprint 5 workflows remain outside this
package.

The signed candidate was built and assembled by [workflow 38739455545](https://github.com/scottconverse/civiccast-native/actions/runs/38739455545)
from package source `24c91a2ef7f9bd42bfa3ad9b7119e0c9f9e44168`. The
signed installer is `CivicCast (Native)_1.0.0-beta.18_x64-setup.exe`, SHA-256
`47d49e99d584d0907e66480709d364c26d93053831eb2fb5e15f7bc4b5aa85f5`.
Its Authenticode signature was Valid on the assembled kit. The workflow also
completed the five signed runtime packs, station bundle, and exact-source PDF
and Word manuals. The later release-branch changes update the downloader's
default tag and this record; they do not change the signed installer or packs.

A focused fresh-install check started this exact kit in Windows Sandbox on
October 15, 2026. The Sandbox guest logged off before the check produced an
installer exit code, service status, or health result. Installation is therefore
**unverified by this attempt**; no install pass is claimed. The automatically
triggered broad Gate A run was cancelled to avoid overlapping Sandbox work and
is not a pass. No Beta 18 soak is claimed.

The release-branch CI completed 11,530 unit passes with 16 failures and 101
skips; its informational randomized run completed 11,534 passes with 16
failures and 102 skips. The failed assertions concern Beta 17 wording/version
bindings, a manual contents count, public-copy policy fixtures, and the
downloader default (corrected on the release branch after the signed build).
The dependent claims-evidence job failed because the unit job was not green.
Focused operator build, TypeScript, lint, accessibility, dependency/security,
Windows installer compile, signed package build, and manual generation passed.
This record does not claim green full CI.

Beta 17's installed-package observations remain [Beta 17 evidence](v1.0.0-beta.17-verification.md),
not Beta 18 installation evidence. Beta 18 changes the operator station-import
interface and documentation; it does not change the installer engine, service
identity, native runtime packs' source, or transport-stream output code.
