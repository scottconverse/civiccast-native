# v1.0.0-beta.10 verification

**Status: OWNER-HELD UNPUBLISHED CANDIDATE.** `v1.0.0-beta.10` has not been
published. When it is, it will be published as a GitHub pre-release ("Beta
Candidate"), not as a production release. Until then `v1.0.0-beta.7` remains
the public download. `v1.0.0-beta.8` and `v1.0.0-beta.9` were never
published; their work is included in beta.10.

This record states what was and was not proven for the beta.10 build. It
describes evidence that exists today. It does not report a Gate A result, a
published installer, or a human field-tester sign-off, because none of those
exist yet for this build.

## Eight-hour watched run on a three-channel station

Run name `rung-8h-c16-20261001-163004`, from 2026-10-01 16:30:04 to
2026-10-02 00:30:14 (Mountain time) on the lab station, with three channels
(education, government, public) airing real programs at the same time and
captions embedded in the output. Evidence is in this repository under
`ops/beta10-oversight/`; the run's own summary is
[`verdicts/rung-8h-c16-20261001-163004--VERDICT-NOTE.md`](../../ops/beta10-oversight/verdicts/rung-8h-c16-20261001-163004--VERDICT-NOTE.md).

| Measure | Result |
| --- | --- |
| Service process | One process for the whole 8 hours: no restart, no crash |
| Slate or filler after startup | None |
| Station errors / watchdog firings | 0 / 0 |
| Verify checks | 41 run; 40 OK; 1 raw FAIL (check 11, see below) |
| Loudness, 240-second windows | 16 of 16 pass on all three channels (target -16 LUFS, plus or minus 1) |
| Program changes scored | 50 watched; 0 holes, 0 errors; picture gap at most 0.033 s, sound gap at most 0.041 s |
| Preparations | 51 logged; longest 389 s, all inside the roughly 11-minute lead time |
| Conform cache / disk | 46 GB of the 60 GB budget used; 810 GB free |

**The one raw FAIL.** Verify check 11 (18:23, education) reported that the
education playlist did not advance between the verifier's two samples. It was
judged a sampling blip, not a stall, because the run's own 30-second sampler
showed education advancing before and after, the playlist counted 147 segments
in about 293 seconds (the normal rate), the control-plane log shows the same
program and worker the whole time, and the other ten checks passed freshness
on every channel. The adjudication is in
[`verdicts/rung-8h-c16-20261001-163004--ADJUDICATION-verify-11-education-freshness.md`](../../ops/beta10-oversight/verdicts/rung-8h-c16-20261001-163004--ADJUDICATION-verify-11-education-freshness.md).
The adjudication itself notes a gap of about 97 seconds in the sampler while
the verifier ran, so a sub-five-second hiccup inside the verifier's own two
samples cannot be ruled out by direct observation. The run's raw verdict is
printed as FAIL and that raw result stands in the record.

**Loudness windows.** A window whose own source is too quiet for the leveling
ride's maximum lift is listed, not failed. All 16 windows in this run passed;
the station's leveling check also logged two programs with a worst
four-minute stretch of 1.94 LU and 1.39 LU while the windows still passed.

**Education dead-air fix.** Before the fix, a program change on the education
channel once left it black and silent for about 34 hours. The watchdog that
ends a stuck program change (the final fix in this build) was in place for the
run; the exact stall case did not recur. A neighboring 3.3-second tail on the
public channel (20:36) resolved correctly.

## Known limits of this build

These are measured and listed on purpose.

1. **Live-caption audio can be dropped under heavy load.** The caption worker
   logged 13 catch-up discard events in 8 hours. On a quiet machine the total
   was about 160 seconds of audio on two channels (the earlier internal build
   lost 75 seconds in the same kind of run). Seven of the 13 events were small
   ones between 18:40 and 18:43 that coincided with disk scans the lab
   coordinator was running, so they are not counted in that quiet-machine
   figure. Captions stay on the air, but some spoken audio gets no caption. Cause: the caption worker falls behind during long first-time
   media preparations. A fix is the next work item and is not in this build.
   Captions matter legally for Colorado public-access use, so stations that
   need loss-free captions should weigh this limit.
2. **Two program-change first attempts aborted and self-recovered.** On the
   government channel, a change at 22:23 (timeout) and one at 22:55 (error)
   aborted at a sub-second tail boundary on three-part programs. Each
   recovered in about 3 seconds with no on-air effect.
3. **One single-frame video drop.** One known 0.033-second video drop at a
   part-to-part join inside a program (government, about 22:50).
4. **Quiet source stretches are listed, not leveled.** A stretch of a source
   that is too quiet for the leveling ride is reported, not leveled.
5. **Eleven daemon and automation unit tests fail identically** on the
   installed (live) tree and on the candidate tree. They are pre-existing and
   unexplained, and this build did not cause them.
6. **An unexplained rebuild** of a long cached program seen in the previous
   internal run (07:53) remains unresolved.

The lab coordinator also recorded its own slips during the run (disk scans at
normal priority, a monitor that was silent for two hours, and an early wrong
statement about the education channel), listed in the verdict note, so the
run is not described as perfectly clean.

## What is not proven

- **Gate A has not been run for this build.** The formal three-lane station
  acceptance (clean install, upgrade over the previous published release, and
  download-only upgrade) has not been run on a beta.10 installer.
- **No installer has been built from this source, signed, or published.**
- **No human field-tester has signed off** on this build, and it has not been
  operated at a real station.
- The eight-hour run is on one lab machine with three channels. It is not a
  24-hour or 72-hour soak; longer runs were not part of this evidence.
- Physical DeckLink SDI capture and output, real cable-operator headend
  acceptance, and sustained production use at a real PEG station remain
  unproven, as for earlier releases.

## Acceptance boundary

This evidence shows that the beta.10 playout engine held three channels on air
for eight hours with clean program changes and in-range loudness on a lab
machine, and that the previous long dead-air failure did not recur. It does
not replace the release gates, human operation, or station and headend
acceptance on the owner's target machines. Until those happen, beta.10 is a
beta candidate and `v1.0.0-beta.7` stays the published release.
