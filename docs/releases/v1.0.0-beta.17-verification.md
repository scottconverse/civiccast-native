# CivicCast v1.0.0-beta.17 package verification

Beta 17 is a published beta. Its source includes the completed Sprint 5
subscriber delivery, Podcast, and underwriting daypart changes. Paywall email
delivery remains deferred until the media origin enforces access grants.
Remote-guest output, bulletin-board media, station-import UI, and native viewer
completion remain open work and are not claimed by this package.

The [release page](https://github.com/scottconverse/civiccast-native/releases/tag/v1.0.0-beta.17)
contains the signed installer, runtime packs, station-model archive parts,
release-matched downloader, manuals, and checksums. This package was built by
[workflow 38723457194](https://github.com/scottconverse/civiccast-native/actions/runs/38723457194)
from `597b97fd21ad1e9e5fd52bb399f81214ffdb88f0`. PR #251 merged as
`4a5804608c38774bc04b4c2a5c6f34f56ebdea26`, the release tag target. The
intervening branch commit changed only a PostgreSQL test fixture; it did not
change shipped bytes. Installer `setup.exe` SHA-256:
`985cb617d020065d56f100c7587480d4726e2d5b89e806deca00658536c0d968`.
The release has 26 assets; `SHA256SUMS.txt` lists the file hashes.

The exact signed installer exited 0 in Windows Sandbox on October 15, 2026.
The installed `CivicCastSupervisor` service was Running with Automatic startup.
The bundled offline AI and caption activation self-tests passed. The station
health endpoint, operator console, resident portal, and access-control probe
passed. The installed station reached its real loop and caption checks.

The same Sandbox run did not prove the shipped GStreamer transport-stream
output: its government-channel TSDuck receiver timed out while the station
reported fallback slate. Separate synthetic fallback encoders sent valid
transport streams on all three channels. Gate A was cancelled after that
non-passing T4 result; it is not recorded as a pass or as a Beta 17 long soak.
The earlier Beta 16 installed GStreamer smoke result remains Beta 16 evidence.
No installer, native-runtime, or egress-engine code changed in Beta 17.

Broad CI recorded 11,544 passing unit tests and two failures in assertions for
obsolete documentation wording. The dependent claims-evidence job failed
because the unit job was not green. Routine lint, security, accessibility,
installer compile, and Windows package build checks passed. These results are
reported as they occurred; this record does not claim a full green CI run.

The published download's asset count and byte sizes were checked against the
prepared asset list before making the draft public. Historical Beta 16 results
remain in the [Beta 16 record](v1.0.0-beta.16-verification.md).

The signed build's bundled PDF/Word manual and in-app Help were generated
before publication. Their edition paragraph still calls Beta 17 a candidate
and Beta 16 the current published package. The repository's post-publication
manual source and front-door guidance correct that status, but they do not
alter the already signed installer or its published manual assets. This is a
documentation discrepancy in the immutable Beta 17 package.
