# CivicCast v1.0.0-beta.19 package verification

Beta 19 completes Sprint 5's software scope: remote-guest video and audio can
enter channel output with take and handback controls; bulletin-board output
can include a selected live-video zone and an uploaded audio bed; the native
viewer applications add station selection, live and replay browsing, search,
artwork, deep links and platform playback controls. The Beta 17 and 18
publication, underwriting and station-import work remains included.

PDF/Word manuals were built by [candidate workflow 38797808863, attempt 2](https://github.com/scottconverse/civiccast-native/actions/runs/38797808863)
from source `7d61cbede3123a65b4a0d6d4b413ae99edbc3f04`. All four workflow
jobs passed. The installer identifies itself as `1.0.0-beta.19`, its
Authenticode status is **Valid**, and its SHA-256 is
`62cd8d9b43c8ce823e90b5aa0e2f7b1fedb233353dd96c843063cd328f83f17e`.

Focused source checks passed for the remote-guest media path, board output,
