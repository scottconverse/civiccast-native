## Published assets

The publisher verified the local release manifest, Authenticode signature,
Gate A verdicts, and all uploaded asset names and sizes before making the
release public. GitHub reports the same SHA-256 digests as the local files for
all eight release assets: `setup.exe`, its sidecar, five runtime packs, and
`SHA256SUMS.txt`.

The roughly 21 GB station AI-model bundle is not hosted on GitHub. A first
airgapped installation needs that bundle supplied by USB or LAN alongside the
published installer and runtime packs. An upgrade from beta.5 can use the
models already cached on the station.

## Acceptance boundary

This evidence proves the signed package, the three supported installation
journeys, and sustained captions-off GStreamer playout on the physical R16
tester. It does not replace human operation and station/headend acceptance on
the owner's target machines. Live captions remain off by default; the caption
module is present and can be enabled, while offline caption generation remains
available after hours.
