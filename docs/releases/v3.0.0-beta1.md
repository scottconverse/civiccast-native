## What This Beta Is

CivicCast 3.0.0-beta1 is the first public beta cut for the software-defined PEG station-in-a-box line. It is intended for early adopters, controlled tester installs, and Longmont Public Media validation, not production-certified deployment.

## Major Surfaces

- 24/7 multi-channel playout and egress supervision.
- GStreamer playout engine and protocol seams.
- Commit-to-air and software force-matrix controls.
- CG/bulletin-board designer and feed-backed bulletin paths.
- Scheduled recording, meeting agendas, chapters, records, proof trail, and reporting.
- Caption, loudness, secondary-audio, and EAS software-display layers.
- Operator, public portal, installer, and six native OTT starter app trees.
- Optional default-off subscription paywall.
