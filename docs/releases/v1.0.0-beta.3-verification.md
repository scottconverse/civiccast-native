## Scope

This verification covers the Gate A station-acceptance lanes (clean
install, cross-version upgrade, download-only) and the publish-time asset
integrity checks above. It does not itself constitute field proof across
many machines, live external provider delivery, physical SDI/DeckLink
capture, real cable-operator headends, or unattended multi-day station
operation -- see "What's proven in this candidate" and "Honestly scoped" in
[README.md](../../README.md) for what has and has not been proven.
