## Release-review repair and local verification

Release review reproduced a race not covered by the earlier tests: an old
publisher could pass its generation check, pause while a new session reset
the sidecar, then restore stale text. An old scan could also attach the new
generation to old audio and move a new writer's reused chunk filename.

The repair uses per-channel locking for reset, generation validation,
publication, file moves and session state. Audio reads and ASR remain outside
the lock. Six regression cases cover both publish paths, reset during input
read or ASR, queued model preparation and flush. The independent reviewer
reran the original two-thread reproductions and found them corrected.
Historical review evidence from an already-running ASR job may still finish
persisting; that is distinct from publishing it into the current session.
