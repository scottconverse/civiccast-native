## Local CI

The local 3.2 runner is:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/run_local_3_2_lpm_contract_lab_ci.ps1 -ArtifactRoot <artifact-root>
```

For each run, the runner writes its exact run id, completion timestamp, source
hashes, changed-file list, and pass/fail result into:

- `<artifact-root>/summary.json`
- `<artifact-root>/source-state.json`

The final GauntletGate report for a given pass names the exact artifact root used
for that pass. This status document intentionally avoids embedding run-specific
source hashes inline, because those hashes belong to the generated artifact for
the exact run.

## Wall-Clock Soak

Elapsed soak evidence is generated separately from the fast local CI runner:

```powershell
uv run python scripts/run_lpm_contract_lab_wall_clock_soak.py --duration-seconds 14400 --interval-seconds 300 --profile all --probe-real-software --require-software-lab --artifact-root artifacts/wall-clock-soak/<run-id>
```

The runner repeats the Stage 8 contract lab until the requested elapsed duration
is reached. It writes `summary.json`, per-cycle artifacts, source-state hashes,
and a README. It fails if any required cycle fails, if any selected OBS/vMix
software proof is missing when `--require-software-lab` is set, or if elapsed
time is shorter than requested.
