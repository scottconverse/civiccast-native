## REL-001 Release Artifact Automation Proof

Added release artifact automation:

- `scripts/build_release_artifacts.py`
- `.github/workflows/release-artifacts.yml`

The workflow builds release-candidate assets on tag or manual dispatch and
uses GitHub artifact attestations for generated assets. It does not create or
move tags.
