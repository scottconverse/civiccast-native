## Nightly Gate

The `nightly-publish-soak` workflow now runs:

- on nightly cron at 04:20 UTC;
- on `workflow_dispatch`;
- on pull requests that touch publish, archive, syndicate, podcast,
  subscription, soak-test, or workflow files.

The workflow installs the project, runs `tests/publish/test_soak.py`, generates
`artifacts/v1.0-publish-soak-result.json`, and uploads that JSON as the
`v1.0-publish-soak-result` artifact.

## Soak Coverage

Each deterministic publish-soak iteration creates a public-record meeting asset,
runs preflight, approves every publish surface, and verifies:

- canonical portal surface succeeds;
- Internet Archive succeeds and returns a SHA-256 verification hash;
- local NAS rsync succeeds and returns a SHA-256 verification hash;
- local NAS ZFS succeeds and returns a SHA-256 verification hash;
- YouTube Live reach succeeds;
- YouTube VOD reach succeeds;
- podcast audience surface succeeds;
- subscriber notification audience surface succeeds;
- dashboard state reaches `archive_verified`;
- audit events are emitted for every surface.
