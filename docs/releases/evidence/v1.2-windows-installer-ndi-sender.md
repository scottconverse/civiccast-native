The clean prebuilt-FFmpeg path was checked first. NDI's official guidance says
precompiled FFmpeg with NDI support is not distributed for licensing reasons.
This run therefore does not add an untrusted FFmpeg binary. Building FFmpeg
locally remains blocked until SDK headers/import libraries and a compatible
Windows build toolchain are installed.
