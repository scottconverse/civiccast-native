## Baseline Policy

This is the v1.0 baseline. The fixtures use deterministic local adapters so CI
can enforce quality contracts without external model credentials or GPU model
downloads. Future live-model runs must meet or exceed these fixture tolerances
or deliberately replace the baseline in a tracked release evidence update.

Translation includes a `comet_adequacy` score. It is a deterministic local
adequacy proxy with COMET-shaped release semantics, not a neural COMET model
download. It exists so v1.0 can enforce a stable translation adequacy floor in
CI; a live COMET scorer can replace it after v1.0 without changing the evidence
shape.
