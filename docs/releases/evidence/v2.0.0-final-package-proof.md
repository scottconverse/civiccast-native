## VirtualBox Clean Windows Installer Execution

The native installer execution proof is recorded separately in
`docs/releases/evidence/v2.0.0-virtualbox-clean-windows-proof.md`.

That proof ran a v2.0.0 Windows setup executable from the same release line in
a fresh Windows 11 Enterprise Evaluation VM, installed and launched the
CivicCast Installer app, drove the WSL2 approval and reboot path, updated WSL,
and surfaced the expected no-virtualization blocker. The final rebuilt release
assets above have different SHA-256 values because the Windows installer bundle
is not byte-reproducible across local builds.

## Proof Boundary

This proof confirms that v2.0.0 produces a real Windows Tauri setup executable,
tester package, clean Windows proof kit, wheelhouse, and Python package, and
that the package installs offline in both a clean Windows venv and a WSL2
fresh-user sandbox. It also records a full local Docker cleanroom pass at the
final release commit.

This is not an installer-to-dashboard runtime proof on a WSL2-capable clean
Windows target, app-store publication proof, live hardware proof, hosted relay
proof, legal certification, or production deployment proof.
