# v2.0.0 VirtualBox clean Windows installer proof

Date: 2026-06-01

Status: `blocked by VM virtualization boundary`
Release gate: `native installer execution captured; installer-to-dashboard runtime still needs a nested-virtualization-capable target`

This evidence records the v2.0.0 Windows setup executable running inside a
fresh Windows VirtualBox guest. The proof confirms the native installer starts,
installs, launches the CivicCast Installer app, requests Windows approval for
WSL2/Ubuntu setup, survives the required reboot path, updates WSL, and reports
an actionable virtualization blocker when the VM cannot expose WSL2.

## Steps Completed

- Created a fresh Windows 11 Enterprise Evaluation VirtualBox VM.
- Copied `civiccast-2.0.0-clean-windows-proof-kit.zip` into the VM share.
- Extracted the proof kit to `C:\CivicCastProof`.
- Captured machine facts, preflight data, WSL status, and WSL distro list before install.
- Launched `VERIFY-AND-LAUNCH.ps1` from the proof kit.
- Installed the NSIS setup executable to the default per-user path.
- Launched the installed `CivicCast Installer` app from the installer finish screen.
- Approved the Windows PowerShell UAC prompt for the installer app's WSL action.
- Observed the app enable WSL2 features and save a `Resume after reboot` state.
- Rebooted the VM and relaunched the installed CivicCast Installer.
- Updated WSL to `2.7.3` from an elevated PowerShell prompt after Windows required it.
- Reran the app's `Install WSL2 Ubuntu 24.04` action.
- Observed the app report an actionable no-virtualization blocker instead of looping.

## Release Boundary

This closes the previously missing evidence that the final v2.0.0 Windows setup
executable can run inside a disposable Windows VM and drive the WSL2 bootstrap
flow through the expected Windows approval and reboot path.

It does not close installer-to-dashboard runtime proof, because this VirtualBox
guest cannot expose the virtualization layer WSL2 needs to start an Ubuntu
distribution. That remaining runtime proof requires a clean Windows target with
nested virtualization, Hyper-V, Windows Sandbox, or equivalent WSL2 capability.
