## Artifact Build

The first full build attempt produced the portable artifacts and wheelhouse, but
the Windows Tauri build could not replace an old local
`civiccast-installer.exe` because Windows reported `Access is denied`. A stale
local `civiccast-installer` process was still present, and this session could
not force-stop it.

The release builder now honors `CARGO_TARGET_DIR`, so the final build used a
fresh Cargo target directory and completed without touching the locked old
binary.

## VirtualBox Clean Windows Installer Execution

Command path: `C:\Dev\Claude\vm-share\civiccast-v200-proof-cleanwin\civiccast-2.0.0-clean-windows-proof-kit.zip`

Result: `blocked by VM virtualization boundary`

The regenerated proof kit was copied into a fresh Windows 11 Enterprise
Evaluation VirtualBox VM named `civiccast-v200-proof-cleanwin`. The NSIS setup
executable launched, installed to the default per-user path, started the
installed CivicCast Installer app, requested Windows approval for the WSL2
action, enabled WSL components, saved a reboot-required resume state, survived
reboot, updated WSL to `2.7.3`, and reran the `Install WSL2 Ubuntu 24.04`
action.

The final app-visible blocker was:

```text
Windows installed WSL components, but this machine does not expose virtualization
for WSL2. Turn on virtualization or ask IT for help, then rerun CivicCast Installer.
```

Evidence: `docs/releases/evidence/v2.0.0-virtualbox-clean-windows-proof.md`

## Proof Boundary

This proof confirms that v2.0.0 produces a real Windows Tauri setup executable,
tester package, clean Windows proof kit, wheelhouse, and Python package, and
that the package installs offline in both a clean Windows venv and a WSL2
fresh-user sandbox. It also confirms the native Windows setup executable runs in
a fresh Windows VM and drives the WSL2 bootstrap through Windows approval,
reboot, WSL update, and an actionable VM virtualization blocker.

This is not an installer-to-dashboard runtime proof on a WSL2-capable clean
Windows target, app-store publication proof, live hardware proof, hosted relay
proof, legal certification, or production deployment proof.
