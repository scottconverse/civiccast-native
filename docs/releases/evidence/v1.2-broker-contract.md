# v1.2 Broker Contract Evidence

Run: `2026-05-19-v1.2-nats-mtls-foundation`

## Contract

`civiccast.platform.broker` is the sanctioned broker substrate boundary for
this hardening slice. It defines:

- `BrokerEvent`
- `BrokerPublishReceipt`
- `BrokerClient`
- `InProcessBrokerClient`
- `get_broker_client`

The documented subject shipped in this slice is `publish.asset.approved`.
Undocumented subjects raise before publish or subscribe.

`civiccast.platform.broker_config` owns the production configuration contract:
production mode requires `CIVICCAST_NATS_URL`, `CIVICCAST_NATS_STREAM` set to
`CIVICCAST_EVENTS`, and a valid durable consumer name. Development and unit
tests may explicitly use the in-process adapter, but production selection does
not silently fall back to it.

`BrokerClient` exposes the canonical v1.2 surface:

- `publish(event)` validates and records a documented event.
- `subscribe(subject, handler)` validates the subject and registers a future
  event handler.
- `replay(subject)` returns recorded events for local verification and tests.

The in-process adapter fans out published events to subscribed handlers after
subject validation.

## Publish Seam

`civiccast.publish.service.build_publish_approved_event()` builds the documented
event payload from the approved publish status. `civiccast.publish.router`
publishes that event through the injected `BrokerClient` after a successful
approval. Preflight failures return before the broker publish call and do not
emit success events.

## NATS Adapter And Provider Import Policy

`civiccast.platform.nats_broker.NATSJetStreamBrokerClient` is the concrete
NATS JetStream adapter behind the same Protocol. It validates the managed stream
configuration, maps `publish.asset.approved` to
`civiccast.publish.asset.approved`, returns immutable publish receipts with
provider ack metadata, supports replay/subscribe through the stable broker
surface, and translates provider failures into operator-actionable errors.

No `nats` provider import exists outside `civiccast.platform.nats_broker`.
