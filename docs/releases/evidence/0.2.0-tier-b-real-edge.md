# 0.2.0 Tier B — real-CDN-edge ramp (measured, 2026-07-08)

**Status:** measured result against a **real Cloudflare R2 edge** (the free
`r2.dev` development endpoint), single geography, zero dollars spent. This is
the real-vendor-edge link in the 0.2.0 scale-evidence chain; the lab links are
[the direct ceiling](../0.2.0-direct-delivery-ceiling.md),
[the switch validation](../0.2.0-switch-validation.md), and the Tier A
cache-contract lab.

## What ran

A real rolling live window (2s cadence, 6-segment window) published through
the real `LiveCDNPublisher` + Cloudflare R2 adapter to a real bucket whose
credentials were provisioned by the **R2 concierge from one pasted API
token** — then tiered emulated viewers polled the real public URL on the true
HLS cadence. Zero-spend was enforced structurally: the harness pre-flight
projects every run's operation count and **refuses** runs that would leave
R2's free tier (this run projected 173k Class B reads ≈ 1.7% of the free
month; teardown evicted every object, leaving storage at zero).

## What this proves — and what it deliberately does not

1. **The station-side path works end-to-end against a real vendor edge.** At
   25–50 concurrent viewers: 100% success, ~2-second worst-case freshness
   (staleness p95 = 1 segment tick) through a real bucket and real public
   host, with the cache headers CivicCast uploads served verbatim by the edge.
2. **The `r2.dev` development endpoint's policy ceiling, measured.**
   Cloudflare documents `r2.dev` as a rate-limited development URL, and the
   ramp confirmed it empirically: clean at ~25 req/s, heavy 429 throttling at
   ~100 req/s, and a transient source-level block at ~500 req/s that fully
   recovered within minutes (the 25-viewer probe above ran clean afterward).
   **This is the vendor's dev-endpoint posture, not a CivicCast defect and
   not a CDN capacity result.**
3. **The production surge path is a custom domain in front of the bucket** —
   Cloudflare's actual CDN then caches at the edge, so viewer requests are
   fan-out cache hits and the bucket sees ~1 read per segment regardless of
   audience size (the O(1) origin-offload invariant the Tier A lab proves
   against the cache contract). The thousands-of-viewers fan-out on that path
   is the CDN vendor's core documented capacity; a station validates it at
   beta by bringing a domain. No loopback or dev-endpoint number is passed
   off as that result.
