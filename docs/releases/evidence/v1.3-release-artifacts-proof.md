## Tester Trust Notes

- The Windows tester package is unsigned.
- Testers should download only the private GitHub Release `.exe` asset.
- Testers should compare the published SHA-256 before running the installer.
- A Windows SmartScreen warning is expected for this tester build because
  Authenticode signing is outside this tester gate.
- Normal testers should not install from repository source ZIPs, tester handoff
  files, or Git LFS-backed files.
