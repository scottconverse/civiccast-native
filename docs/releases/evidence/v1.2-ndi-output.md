## Scope

This evidence records the scoped NDI output slice. CivicCast now has:

- `civiccast cable ndi-plan` for a deterministic FFmpeg local-file-to-NDI
  command plan;
- `civiccast cable ndi-check` for host readiness detection through the existing
  FFmpeg wrapper;
- `tools/ndi-ffmpeg-sender`, an internal lab sender that launches FFmpeg,
  reads BGRA rawvideo frames, and publishes them through the local NDI runtime;
- tests that cover command planning, missing media, unsafe channel names,
  NDI muxer detection, local sender fallback, missing muxer states, and CLI
  JSON output.

## Proof Boundary

This slice proves the NDI command contract and a local internal sender path.
The installed host FFmpeg still does not expose an NDI output muxer, and the
installed NDI Tools package provides runtime DLLs without SDK headers or import
libraries. For internal public-access-station testing, CivicCast now provides a
lab sender that uses FFmpeg for decode/generation and publishes the resulting
rawvideo frames through the NDI runtime. This is not a redistributable
precompiled FFmpeg+NDI binary and is not claimed as public release packaging.
