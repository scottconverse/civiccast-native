# v2.0.1 clean Windows proof

Date: 2026-06-02

Status: `partial`
Release gate: `native installer execution passed; installer-to-dashboard runtime remains blocked by VM virtualization boundary`

This evidence records the v2.0.1 Windows setup executable running inside a
freshly rebuilt Windows 11 Enterprise Evaluation VirtualBox guest. The proof
confirms the release asset installs, launches, shows the rewritten
plain-English Windows helper copy, drives the Windows approval/reboot/WSL update
path, and stops with an actionable blocker when the VM cannot complete the
helper runtime.

## Release Boundary

This is a partial pass. The v2.0.1 release asset installs and launches on a
truly clean Windows 11 VirtualBox VM, verifies the artifact hash, shows the
rewritten plain-English Windows helper copy, performs the required Windows
approval/reboot/update path, installs WSL 2.7.3, and stops with an
understandable blocker when the VM cannot finish the helper runtime.

This does not prove installer-to-dashboard runtime on a WSL2-capable clean
Windows target. That remaining proof still requires a clean Windows host or VM
where Ubuntu can run under WSL2.
