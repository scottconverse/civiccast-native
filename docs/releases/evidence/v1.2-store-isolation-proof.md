# v1.2 Store Isolation Proof

Run: `2026-05-18-v1.2-internal-hardening`

## Contract

Router modules no longer own mutable default store singletons. Default store
ownership lives on each `create_app()` instance through
`app.state.store_bundle`.

## Proof

- `civiccast.platform.stores.AppStoreBundle` is the app-owned store factory
  bundle.
- `civiccast.app.create_app()` creates a fresh in-memory store bundle for each
  app instance when `DATABASE_URL` is unset.
- When `DATABASE_URL` is set, `create_app()` swaps the relevant store factories
  in `app.state.store_bundle` to Postgres-backed factories while preserving
  lazy connection behavior.
- Router dependencies resolve from `Request.app.state.store_bundle`; tests can
  still use FastAPI `dependency_overrides`.
