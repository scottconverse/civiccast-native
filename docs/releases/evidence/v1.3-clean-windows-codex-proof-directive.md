# v1.3 Clean Windows Codex Proof Directive

Use this on the freshly reset Windows proof machine after Codex is installed
and signed in. In the pullable tester branch flow, this directive is extracted
by `Run-WindowsTesterDirective.ps1`; keep the cloned repo at
`C:\CivicCastTester\civiccast` available so the final result can be committed
and pushed back to the tester branch. Do not modify product code.

## Proof Package Location

In the pullable tester branch flow, do not copy files by hand. The branch
runner verifies `tester-handoff\v1.3.0\civiccast-1.3.0-clean-windows-proof-kit.zip`,
extracts it to `C:\CivicCastProof`, and then points Codex to this directive.

For the older manual-transfer flow only, transfer this single ZIP from the RTX
machine to the proof machine:

- Source on RTX:
  `C:\Dev\Claude\repos\scottconverse\civiccast\artifacts\release\v1.3.0\civiccast-1.3.0-clean-windows-proof-kit.zip`
- Destination on proof machine:
  `C:\CivicCastProof\civiccast-1.3.0-clean-windows-proof-kit.zip`

Extract it so the proof machine has:

- `C:\CivicCastProof\incoming\civiccast-1.3.0-windows-setup.exe`
- `C:\CivicCastProof\SHA256SUMS.txt`
- `C:\CivicCastProof\VERIFY-AND-LAUNCH.ps1`
- `C:\CivicCastProof\proof-directive.md`

The proof kit contains the installer under test. In either flow, do not copy
repo working directories, build folders, or old CivicCast state to the proof
machine.

## Preflight Note

Windows 11 still reports an NT version beginning with `10.0`. Do not reject a
machine as "Windows 10" solely because the version starts with `10.0`. Treat
build `22000` or newer as Windows 11 and record the product name plus build in
the report.

## Prompt For Codex On The Clean Windows Machine

```text
You are Codex on a freshly reset Windows CivicCast proof machine.

Goal: run the v1.3.0 clean Windows installer-to-dashboard release proof for
CivicCast and produce a concise evidence report. Do not modify the product repo.
Do not tag or release anything.

Run this as a collect-and-continue proof. Do not stop for small recoverable
mismatches such as a prompt/runner version mismatch, minor label difference,
missing optional screenshot, or expected filename/path mismatch when an
equivalent actual file can be found. Record each mismatch as a finding, use the
actual observed path or label, and continue to the next proof step.

Stop immediately only for a blocker that prevents safe continuation: artifact
hash mismatch, installer cannot launch, UAC was canceled when Windows requires
elevation, destructive cleanup risk, missing required proof artifact with no
equivalent file, dashboard cannot be reached after retry, or a secret exposure
that would make further screenshots unsafe.

Proof root:
- C:\CivicCastProof

Artifact package:
- Pullable branch flow:
  C:\CivicCastTester\civiccast\tester-handoff\v1.3.0\civiccast-1.3.0-clean-windows-proof-kit.zip
- Manual-transfer flow:
  C:\CivicCastProof\civiccast-1.3.0-clean-windows-proof-kit.zip

If `C:\CivicCastProof\VERIFY-AND-LAUNCH.ps1` already exists, the kit has
already been extracted by the runner; do not hunt for another copy. If the kit
is not already extracted, extract the available package to `C:\CivicCastProof`.
Then run:

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
C:\CivicCastProof\VERIFY-AND-LAUNCH.ps1

The verifier must confirm:
- Windows 11 by product/build, treating build 22000+ as Windows 11 even though
  the NT version starts with 10.0
- Current user
- Installer SHA-256
- No pre-existing CivicCast state under Program Files, LOCALAPPDATA,
  C:\CivicCast, or WSL distros unless created during this proof

Artifact under test after extraction:
- C:\CivicCastProof\incoming\civiccast-1.3.0-windows-setup.exe

Steps:

   - OS product name, version, and build

5. In the dashboard, complete first-admin setup and save/print the recovery kit.
6. Verify backup destination and run restore rehearsal.
7. Add source/test media through Setup.
8. Run private rehearsal.
9. Confirm Safe to broadcast state and resident preview.
10. Generate a support bundle and confirm it does not expose tokens, passwords,

11. Capture screenshots for installer start, WSL/reboot/resume if shown,

12. Write a final report to C:\CivicCastProof\reports\v1.3-clean-windows-proof.md with:

    - artifact hash
    - exact pass/fail status for each step
    - all recoverable findings collected while continuing

    - any operator friction or confusing wording

Pass criteria:
- The installer reaches the operator dashboard without requiring terminal commands.
- WSL2 Ubuntu 24.04 starts successfully.
- First admin, recovery kit, storage, upload/source/test media, private
  rehearsal, resident preview, backup/restore, and support bundle all complete.
- No secret values appear in the report or screenshots.
```

If this proof was launched from the pullable tester branch, record and push the
result before stopping. Use the same runner that launched the proof:

```powershell
$Repo = "C:\CivicCastTester\civiccast"
$Runner = Join-Path $Repo "tester-handoff\v1.3.0\Run-WindowsTesterDirective.ps1"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Runner `
  -Mode RecordResult `
  -Result "PASS" `
  -Blocker "None" `
  -Summary "Real final report summary: include machine details, commands run, artifact hashes, installer/dashboard progress, support bundle status, screenshot/log paths, and pass/fail rationale."
```

If the proof failed, use `-Result "FAIL"` and put the exact failure in
`-Blocker`. The only repo change made by the tester machine should be the new
Markdown result file under `tester-handoff/v1.3.0/test-results/windows/`.

Return the final report and any redacted screenshots/logs to the RTX machine for
release-ledger update as a secondary convenience, not as a replacement for the
pushed tester result.
