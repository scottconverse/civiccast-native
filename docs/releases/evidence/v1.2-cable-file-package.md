## Implemented Local Contract

- Cable package builder requires real local media and caption sidecar files.
- Package directory contains copied media, copied captions, `manifest.json`,
  and `SHA256SUMS`.
- ZIP package receives a package-level `sha256:` verification hash.
- CLI command `civiccast cable package` produces the package for integrators.
- Publish dashboard exposes optional `Cable file package` surface.
- Missing output configuration, media, or captions fail with operator-actionable
  next steps and do not block archive verification.
