# v1.8.9 Integrated Parity Proof

Purpose: prove that the v1.8 feature set is represented by generated contracts and tracked parity evidence before v2.0.0 release-candidate packaging.

Command:

```powershell
uv run python scripts\verify_v189_integrated_parity.py
```

The proof script reads:

- `docs/openapi.json`
- `docs/spec/2.0/parity-evidence-matrix.json`

It verifies generated API contract coverage for:

- app platform and EPG;
- CG bulletin board;
- contributor workflow;
- gated and preroll playback policy;
- analytics and EPG export;
- remote ingest relay;
- broadcast facility router controls;
- external captions and live overlays.

Expected result: `status` is `passed`, `gap_count` is `10`, and `missing` is empty.

This is a software integration proof. It does not prove app-store publication, live hardware validation, hosted relay credentials, production analytics traffic, legal certification, or managed-service operation.
