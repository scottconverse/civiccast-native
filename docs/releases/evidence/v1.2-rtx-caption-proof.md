## Proof Command

Command:

```powershell
$env:PATH='C:\Users\scott\.lmstudio\extensions\backends\vendor\win-llama-cuda12-vendor-v2;' + $env:PATH
.\.venv\Scripts\python.exe scripts\benchmark-caption-runtime.py `
  --audio .agent-runs\2026-05-20-v1.2-rtx-caption-proof\fixtures\civiccast-synthetic-tts-caption.wav `
  --truth .agent-runs\2026-05-20-v1.2-rtx-caption-proof\fixtures\civiccast-synthetic-tts-caption.txt `
  --output .agent-runs\2026-05-20-v1.2-rtx-caption-proof\rtx-caption-benchmark.json `
  --model large-v3 `
  --device cuda `
  --compute-type int8 `
  --language en `
  --beam-size 5 `
  --chunk-seconds 4.0 `
  --vocabulary-term "Councilmember Rivera" `
  --initial-prompt "Civic meeting transcript. Prefer exact civic names and agenda language."
```

The command uses `scripts/benchmark-caption-runtime.py`, which constructs
`civiccast.captions.runtime.FasterWhisperRuntime` and calls
`faster_whisper.WhisperModel`. The deterministic live-caption adapter is not
used on this path.
