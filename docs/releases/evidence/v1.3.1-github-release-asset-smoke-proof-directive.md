# v1.3.1 GitHub Release Asset Smoke Proof Directive

Use this directive after the v1.3.1 GitHub Release is published.

## Goal

Prove that a tester can start from the published GitHub Release Windows setup
asset, not from local build output, `tester-handoff/`, repository source ZIPs,
or Git LFS-backed files.

## Inputs

- Release page: `https://github.com/scottconverse/civiccast/releases/tag/v1.3.1`
- Installer asset: `civiccast-1.3.1-windows-setup.exe`
- Checksum asset: `CivicCast-v1.3.1-SHA256SUMS.txt`
- Manifest asset: `civiccast-1.3.1-release-artifacts-manifest.json`

## Required Rules

- Do not clone the repo for installer acquisition.
- Do not run Git LFS.
- Do not use local `artifacts/` output.
- Do not use `tester-handoff/` binaries.
- Download the `.exe` from the GitHub Release asset URL.

## Steps

1. Sign in to GitHub with an account that has access to the private beta repo.
2. Open the v1.3.1 GitHub Release page.
3. Download `civiccast-1.3.1-windows-setup.exe`.
4. Download `CivicCast-v1.3.1-SHA256SUMS.txt`.
5. In PowerShell, compute:

   ```powershell
   Get-FileHash .\civiccast-1.3.1-windows-setup.exe -Algorithm SHA256
   ```

6. Confirm the hash matches `CivicCast-v1.3.1-SHA256SUMS.txt`.
7. Run the setup executable.
8. Record whether Windows shows SmartScreen or unknown-publisher warnings.
9. Approve Windows prompts when expected.
10. If a reboot is requested, reboot and reopen the installer.
11. Continue until the operator console opens.
12. Create first admin, save the recovery kit, run backup verification, run
    restore rehearsal, run private rehearsal, confirm resident preview, and
    create a support bundle.

## Result File

Write a markdown report with:

- Release URL.
- Downloaded installer filename.
- Downloaded installer byte size.
- SHA-256 value.
- Whether the checksum matched.
- SmartScreen/signing observation.
- Whether WSL2/Ubuntu setup was guided without terminal commands.
- Whether the operator console opened.
- First-admin/recovery result.
- Backup/restore rehearsal result.
- Private rehearsal result.
- Resident preview result.
- Support bundle path and SHA-256.
- Final result: `PASS`, `PARTIAL`, or `FAIL`.
- Blocker, if any.

Do not paste passwords, recovery codes, provider secrets, private keys,
resident data, or private meeting content.
