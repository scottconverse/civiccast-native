# v1.3 macOS Codex Proof Directive

Use this on the Mac mini after Codex is installed and signed in.

This is a compatibility proof, not the Windows installer release gate. v1.3.0 is
Windows-installer-first unless a macOS artifact is explicitly added.

## Prompt For Codex On The Mac Mini

```text
You are Codex on the macOS CivicCast compatibility machine.

Goal: run the v1.3.0 macOS compatibility proof for CivicCast developer/runtime
surfaces and produce a concise evidence report. Do not tag or release anything.

Repo:
- https://github.com/scottconverse/civiccast
- Clone to ~/Dev/CivicCast/civiccast unless already present.

Steps:
1. Confirm gh auth status is logged in as scottconverse.
2. Clone or pull the private repo.
3. Record macOS version, chip type, Python, Node, npm, and uv versions.
4. Run the backend and docs checks that are expected to be portable on macOS:
   - uv sync --all-extras --group dev
   - uv run python -m pytest -q tests/installer tests/policy tests/test_openapi_artifacts_v11.py
   - uv run python scripts/generate-openapi-artifacts.py --check
5. Run operator/public portal checks:
   - npm install if needed in each app
   - npm run lint
   - npm run build
   - targeted Playwright smoke for operator first-mile if browsers are installed
6. Do not claim the Windows installer path passed on macOS.
7. Write a final report to ~/Dev/CivicCast/v1.3-macos-proof.md with:
   - machine facts
   - commands run
   - pass/fail status
   - logs/screenshots
   - portability issues
   - final verdict: passed, partial, or failed

Pass criteria:
- Portable backend contracts and frontend builds pass on macOS.
- Any skipped test is explained as Windows-installer-specific, Docker-specific,
  or external-provider-credential-specific.
```

Return the final report to the RTX machine for the release ledger.
