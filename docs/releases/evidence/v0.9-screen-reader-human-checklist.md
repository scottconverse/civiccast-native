# v0.9 Screen-Reader Human Verification Checklist

Date: 2026-05-15

Scope: CivicCast v0.9.0 Translation + accessibility hardening.

This file is the required human assistive-technology evidence for the v0.9
release gate. Automated axe, keyboard, and role/name checks are necessary but
not sufficient for this gate.

## Required Result

- Windows + NVDA: pending human pass.
- Windows + NVDA: passed by Sconvesre on Chrome, 2026-05-14 20:07
  public portal and 2026-05-14 20:17 operator portal.
- macOS + VoiceOver: passed by Sconvesre on Chrome, 2026-05-14 20:09
  public portal and 2026-05-14 20:26 operator portal.
- Release may not be called complete until both passes are filled in with no
  unresolved Blocker or Critical issues.

## Windows NVDA Setup

- Machine: Windows workstation.
- Screen reader: NVDA 2026.1 installed with `winget install NVAccess.NVDA`.
- Installation package path:
  `scripts/install-windows-accessibility-tools.ps1`.
- Browser: Chrome or Edge.
- Evidence helpers:
  - NVDA Speech Viewer, if available.
  - Screenshot of each tested CivicCast surface.
  - Written notes below.

## macOS VoiceOver Setup

- Machine: Mac mini.
- Screen reader: VoiceOver.
- Browser: Safari preferred; Chrome optional.
- Start VoiceOver: `Command+F5`.
- Access path:
  - Either run CivicCast locally on the Mac mini, or
  - expose the Windows preview/dev server to the local network and open it from
    the Mac mini.

## Public Portal Flow

Test with keyboard and screen-reader navigation only.

- Page announces as CivicCast public portal.
- Headings are discoverable in order:
  - CivicCast public portal.
  - Live now.
  - Coming up.
  - Published recordings.
  - Follow new recordings.
- Loading state announces what is loading.
- Empty state explains what residents should do next.
- Partial state announces that some sections need attention while keeping
  available content reachable.
- Player is announced as Meeting video player.
- Caption controls are reachable and announced:
  - Off.
  - English.
  - Spanish.
- English and Spanish caption buttons announce pressed/not-pressed state.
- Subscription email field announces its label.
- Subscribe button is reachable by keyboard.
- Confirmation result announces the next step.
- Invalid-token result explains how to recover.
- Unsubscribe result confirms future notices are stopped.
- RSS and podcast links are reachable on mobile width.

## Operator Portal Flow

Test with keyboard and screen-reader navigation only.

- Page announces as CivicCast Operator.
- Banner/header, primary navigation, and main landmarks are discoverable.
- Assets heading is announced as the page heading.
- Search assets field announces its label.
- Theme toggle announces the current action.
- Disabled navigation items are announced as disabled/unavailable.
- Mobile navigation button announces Open navigation.
- Mobile drawer announces as Primary navigation dialog.
- Close navigation control is announced.
