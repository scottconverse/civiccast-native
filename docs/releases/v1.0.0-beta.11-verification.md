## Known limits

Native call timings exclude shared-lock wait and complete caption latency. Periodic output checks establish sampled decoding/freshness/continuity, not semantic transcription accuracy or coverage of every second. CPU-only Medium Whisper fallback has not demonstrated real-time capacity. NVIDIA CUDA support does not imply AMD/Intel GPU support.

The caption implementation's earlier affected regression suite passed 293 tests; inherited automation/diagnostic failures were separately reproduced and documented. This is not a full-repository-green claim. Program-transition retries, lost acknowledgements and automatic capped relay-log trims have occurred during the longer observation. Whole-drive disk-space changes remain partly unattributed; game recordings/caches and Windows app updates were found, not a growing live caption archive. Short observer captures do not establish release-grade loudness. Physical broadcast hardware/headend acceptance and a real station field sign-off remain unproven.

Rollback for the running test station is outside this package preparation: no station installation or restart is authorized by the preparation step. Release package rollback/disposition will be documented after exact artifacts exist.
