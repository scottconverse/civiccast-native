## Product changes

- Whistle is the CPU primary for live captions; Whisper is the fallback and remains the recorded-media engine. Operators can select NVIDIA CUDA for Whisper. The first recognition is published without repeat-agreement gating, inference is serialized across stations, and Needle telemetry is disabled.
- A failed Whisper fallback child is closed before replacement. One immediate replay is retained, then fallback replacement is serialized behind a 30-second cooldown.
- Supervisor startup/readiness now serializes with service ticks and accepts health only from the child it launched. Explicit stop/drain commands remain consumable while channels are disabled; disabled channels cannot be restarted by queued automation commands.
- The installer activates its embedded station assets before service checks. Live cue history and delivery bookkeeping are bounded, and live captions do not create permanent review records or audio-evidence archives automatically.
