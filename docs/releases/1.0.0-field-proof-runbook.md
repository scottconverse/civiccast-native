# CivicCast 1.0.0 Field-Proof Runbook

**Purpose:** `v1.0.0-rc1` proved everything a lab can prove. This runbook turns
the eight remaining field items into exact, no-judgment protocols: what to do,
what evidence to capture, what "pass" looks like, and where the evidence goes.
Any competent operator — or a lower-capability coding assistant — can execute
these without design decisions. When all eight rows are green (or explicitly
waived by the project owner), `1.0.0` final can be cut.

**Evidence rules (apply to every item):**
- Evidence files go under `docs/releases/evidence/1.0.0/<item-slug>/` in a PR.
- Every evidence file records: date, CivicCast version, hardware/software
  involved, verbatim command output or exported logs, and the operator's name.
- Never edit an evidence file after the fact; add an addendum file instead.
- A FAIL is evidence too — commit it, file an issue, fix, re-run.

---

## 1. LPM production hours (`lpm-production-hours`)

**Goal:** ≥ 72 cumulative hours of real on-air playout at Longmont Public
Media with zero unexplained stalls/blackouts, including ≥ 2 live council
meetings end-to-end.

**Prereqs:** rc1 installed on the LPM station PC; channel configured; LPM
staff contact available during the first live meeting.

**Steps:**
1. Install `v1.0.0-rc1` per `INSTALL-WINDOWS.md` on the station machine.
2. Enable the support bundle timer (Settings → Diagnostics) so hourly health
   samples persist.
3. Run normal programming for at least 72 cumulative hours (need not be
   contiguous). Log every operator intervention in a dated `operator-log.md`.
4. For each live meeting: record start/end time, ingest source, and whether
   the recording finalized without retry.
5. After 72h, export the support bundle: Admin → Support → Export bundle.

**PASS:** 72h logged; 0 unexplained stalls (explained ones documented with
cause); 2+ live meetings with clean finalization. Evidence: the support
bundle, `operator-log.md`, and per-meeting notes.

**FAIL handling:** any stall/blackout → keep the support bundle from that
hour, file an issue with the bundle attached, do not reset the hour counter
unless the fix changes playout code.

## 2. Cable-headend device proof (`headend-device-proof`)

**Goal:** the channel-lifetime TS relay feeds LPM's real modulator/headend
chain for ≥ 4 hours including ≥ 2 encoder relaunches, without the headend
dropping the session.

**Prereqs:** access to the LPM headend input (currently fed by their existing
chain — coordinate a maintenance window); the CivicCast box's TS output
connected in place of (or split alongside) the incumbent feed. LPM's known
gear: Cablecast Vio units, AJA Kumo SDI router, AJA Helo / BM 4K Web
Presenter encoders. The MediaKind X2 is closed/out-of-scope — do not touch it.

**Steps:**
1. In a maintenance window, route CivicCast's TS relay output (UDP/RTP per
   `docs/egress`) to the headend input normally fed by the incumbent encoder.
2. Confirm picture + audio on a cable test TV for 30 min.
3. Relaunch the CivicCast encoder process twice (Admin → Egress → Restart
   encoder), ≥ 30 min apart. The relay keeps the TS session alive — the
   headend must NOT lose lock (this is the #151 fix, lab-proven with `tsp`).
4. Continue for a total of ≥ 4 hours. Photograph/record the test TV at start,
   after each relaunch, and at end.

**PASS:** headend lock never lost; both relaunches invisible downstream.
Evidence: timestamps, photos/video, relay log excerpt, operator sign-off.

## 3. Signed Windows installer (`signed-installer`)

> **STATUS — DONE (1.0 beta line).** Authenticode signing shipped via **Azure
> Trusted Signing** in CI (not the local `signtool`/EV-cert path drafted below).
> Verified publisher: **Scott Converse**; see `CODE_SIGNING_POLICY.md` for the
> live posture and `.github/workflows/release-artifacts.yml` for the wiring. Note
> that under Microsoft's 2026 Trusted-Signing CA changes, even a valid signature
> earns SmartScreen reputation over download volume rather than bypassing the
> prompt immediately. The steps below are retained as historical planning context.

**Goal:** the release installer is Authenticode-signed so SmartScreen shows a
named publisher instead of "unknown".

**Prereqs:** OWNER ACTION — purchase an OV or EV code-signing certificate
(EV removes SmartScreen reputation lag immediately; OV builds reputation over
downloads). This is a purchase decision only the owner can make.

**Steps:**
1. Store the cert per the CA's instructions (EV = hardware token/cloud HSM;
   OV = PFX). NEVER commit key material.
2. Add a signing step to the release workflow after the installer build:
   `signtool sign /fd SHA256 /tr http://timestamp.digicert.com /td SHA256 ...`
   (exact flags depend on cert type; the CA's docs are authoritative).
3. Update `CODE_SIGNING_POLICY.md` from "NOT signed" to the real posture.
4. Build a release candidate, download the asset, run
   `Get-AuthenticodeSignature .\civiccast-<ver>-windows-setup.exe` → Valid,
   and confirm the SmartScreen dialog names the publisher on a clean VM.

**PASS:** Valid signature + named publisher on a clean Windows VM.
Evidence: `Get-AuthenticodeSignature` output + VM screenshot.

## 4. Custom-domain CDN fan-out (`custom-domain-cdn`)

**Goal:** the surge switch serves real viewers through a custom-domain CDN
hostname (removing the documented r2.dev dev-endpoint policy ceiling that
throttled the 1000-viewer lab tier).

**Prereqs:** a domain the station controls; the existing Cloudflare account
(R2 bucket `civiccast-media` is already live; keep to the free tier —
standing zero-spend rule).

**Steps:**
1. In Cloudflare, add the domain, then attach a custom domain to the R2
   bucket (R2 → bucket → Settings → Custom Domains). This lifts the r2.dev
   dev-endpoint rate policy.
2. Point the CivicCast CDN adapter at the custom host (Admin → CDN → host).
3. Re-run the Tier B real-edge ramp (`uv run python -m civiccast.load.real_edge_ramp`,
   see `docs/releases/evidence/0.2.0-tier-b-real-edge.md` for the prior
   method) at the 200 and 1000 viewer tiers against the custom domain.
4. Record per-tier freshness/success rates alongside the 0.2.0 numbers.

**PASS:** 1000-viewer tier no longer policy-throttled; success/freshness at
or above the 0.2.0 Tier B 25–50-viewer figures. Evidence: ramp output JSON +
a diff table against the 0.2.0 run. Cost stays $0 (free tier) unless the
owner approves spend.

## 5. Castus real-export validation (`castus-real-export`)

**Goal:** the Castus migration adapter parses a real station's export (the
adapter was built from vendor-format documentation, not a live sample).

**Prereqs:** one real Castus export from any station (ask on PEG operator
lists / Castus user groups; LPM peers may have one). Scrub PII if the station
requires it — the adapter only needs structure, not real resident data.

**Steps:**
1. Put the export under a local (NOT committed) path.
2. Run the migration dry-run:
   `uv run python -m civiccast.migrate --source castus --path <export> --dry-run`
3. Compare the dry-run plan counts (shows/playlists/schedule items) against
   the station's own numbers for the same export.
4. If parsing fails: the failure output is the deliverable — file an issue
   with the (scrubbed) sample attached, fix the adapter test-first, re-run.

**PASS:** dry-run completes; counts match the source station's expectation
within documented tolerance. Evidence: dry-run output + count comparison
(scrubbed of station-identifying data if requested).

## 6. PrimeGov real-PDF path (`primegov-real-pdf`)

**Goal:** the PrimeGov agenda-PDF extraction runs against a real authorized
PrimeGov tenant (the live-API surface was validated read-only against
Longmont; the PDF endpoint is auth-gated and was not).

**Prereqs:** API credentials for one PrimeGov tenant (LPM can request them
from the City of Longmont's clerk office — the city already runs PrimeGov).

**Steps:**
1. Set the documented env vars (see `civiccast/agenda_import/primegov.py`
   header) with the tenant credentials. Never commit them.
2. Run the gated live proof:
   `CIVICCAST_RUN_AGENDA_SOURCE_PROOF=1 uv run pytest tests/agenda_import/test_live_proof_primegov.py -q`
3. Then import one real upcoming agenda through the UI and verify items +
   PDF anchor render on the public portal.

**PASS:** gated test green against the real tenant; one real agenda imported
with correct items. Evidence: test output + a screenshot of the imported
agenda (public data only).

## 7. LPM Cablecast Vio private-API validation (`vio-private-api`)

**Goal:** the Cablecast import path proven against LPM's own Vio units (the
adapter was validated against a public 71k-show Cablecast server; LPM's Vio
runs the private/on-prem variant).

**Prereqs:** read-only API credentials to LPM's Cablecast server (their
FrontDoor/Cablecast admin can create a viewer account); network access from
the CivicCast box.

**Steps:**
1. `uv run python -m civiccast.migrate --source cablecast --url <lpm-server> --dry-run`
   with the read-only credentials.
2. Compare dry-run counts with LPM's own show count.
3. Import into a THROWAWAY CivicCast database first (`CIVICCAST_ALLOW_EPHEMERAL_STORES=1`),
   verify spot-checks (10 random shows: title, runtime, category), then plan
   the real apply with LPM staff.

**PASS:** dry-run + throwaway apply with matching counts and 10/10 spot
checks. Evidence: dry-run output, spot-check table, LPM sign-off.

## 8. Finalization-interrupt DR scenario (`finalization-interrupt-dr`)

**Goal:** close the one deliberately deferred DR scenario: a hard power cut
DURING recording finalization, followed by clean recovery.

**Prereqs:** lab only — a machine or VM where power can be cut (VM hard-stop
is acceptable and reproducible).

**Steps:**
1. Start a scheduled recording; let it run ≥ 5 min.
2. Stop the recording and hard-kill the machine (VM power-off) within the
   finalization window (the window is logged; `civiccast/dr/crash_drill.py`
   shows the drill pattern to adapt).
3. Boot, start CivicCast, and record what the operator sees: the recording
   must be either recovered or clearly marked failed with a reason — never
   silently missing and never a corrupt asset presented as good.
4. Repeat 3 times.

**PASS:** 3/3 runs end in an honest state (recovered, or visibly failed with
reason). Evidence: per-run notes + the relevant log excerpts + asset states.
This one should be scripted into `civiccast/dr/` as a permanent drill once it
passes manually — file an issue for that when closing.
