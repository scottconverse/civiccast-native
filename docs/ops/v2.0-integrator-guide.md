# CivicCast v2.0 Integrator Guide

Audience: technical integrators connecting CivicCast to station infrastructure, apps, analytics, caption systems, routers, relay hosts, and archives.

## Integration Areas

- Public app API and shared app runtime.
- Playback policies, gated access, and RSS entitlement behavior.
- CG bulletin board templates, feed adapters, snapshots, and HLS render planning.
- Contributor submission and review surfaces.
- Analytics reporting, GA4 export, and EPG export.
- Remote ingest relay planning.
- Facility router command planning and scheduled take previews.
- External caption ingest into the caption review queue.
- Overlay compositor planning for bugs, lower-thirds, emergency overlays, L-bars, and squeezebacks.

## Required Proof Discipline

1. Use local software proof for CivicCast-controlled APIs and UI.
2. Use partner/device proof for live routers, caption appliances, hosted relays, analytics accounts, app stores, and production traffic.
3. Record proof in the parity evidence matrix or release evidence docs.
4. Keep secrets out of support bundles and issue comments.
5. Keep direct hardware sends disabled until the station approves the device, route, and rollback plan.
