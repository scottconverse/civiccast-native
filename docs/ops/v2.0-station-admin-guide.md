Audience: station managers and technical admins responsible for installation, upgrade, access, backups, release evidence, and public claim boundaries.

- Parity evidence: `docs/spec/2.0/parity-evidence-matrix.json`

## Required Admin Routine

1. Verify release artifact checksums before installation.
2. Configure durable storage and backup destination.
3. Run restore rehearsal before any public operation.
4. Record rollback artifact path and checksum before each major update.
5. Open a maintenance window before applying updates.
6. Run post-update proof before returning to public broadcasts.
7. Keep support bundles redacted; do not copy secrets into tickets or evidence.

## Claim Boundary

Admins may state that CivicCast has implemented the documented software capabilities that have local evidence. Do not claim app-store publication, live hardware validation, legal certification, managed-service operation, accessibility certification, or production analytics proof unless separate evidence exists.

## Escalate Before Operation

Stop and escalate if backup is not ready, restore rehearsal has not passed, rollback artifact proof is missing, `/health` fails, `/api/version` does not match the intended release, or a parity surface is marked `human_blocked`.
