CivicCast for Windows

Current release posture: v1.0.0-beta.11 is the current release (published 2026-10-08), a GitHub pre-release. It is still a beta, not a finished production release. v1.0.0-beta.10, v1.0.0-beta.7, v1.0.0-beta.5, v1.0.0-beta.4 and v1.0.0-beta.3 (the first downloadable release) are superseded.

Download setup.exe and the runtime .ccpack packs from the v1.0.0-beta.11 GitHub Release. Verify the SHA-256 checksum against the published SHA256SUMS.txt and the Windows Authenticode signature before running the installer -- see the current release verification record for the exact install and output scope. The package was refreshed in place over an existing Beta 11 host; clean install, repair, Beta 10 upgrade, and longer capacity tests were not run for this package. A first-time install also needs the station folder of speech and AI model files (about 21 GB), which is not on the release page and is supplied in a kit by USB or network copy. The Windows setup step does not download them: with only setup.exe and the packs it stops with exit code 110 or 123. The PDF manual's release-status text is a build-time snapshot; use the verification record for final package status. Chapter 10 of the User Manual explains the folder layout and every exit code.

Historical Beta 10 test result and private tester kits

The superseded v1.0.0-beta.10 release passed its clean-install Gate A lane (10 of 10 criteria) in Windows Sandbox on 2026-10-02. Its upgrade and download-only lanes were not run. See its historical verification record.

If Scott supplied you with a private tester kit (for example, the USB station bundle for a first-time install), use only the installer and checksum in that kit. Verify the SHA-256 checksum and the Windows Authenticode signature before running the installer. Do not substitute an installer from another build.

The Windows installer shows a visible progress heartbeat while setup is visibly active. The Beta 11 in-place refresh preserved the install location and enabled schedule-loop setting; a cross-version upgrade was not tested for this package.

Evidence boundary

Source tests, signed artifacts, and controlled Windows Sandbox checks do not establish field readiness by themselves. Physical DeckLink capture, real headend integration, and production operation remain pending until separately proven.
