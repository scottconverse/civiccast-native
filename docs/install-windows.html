Download and install

Use the Windows installation guide and its PowerShell command. The helper downloads the signed installer, runtime packs and complete signed station model bundle, verifies them and prepares the correct folders before setup starts. You do not need Git, Python, Docker, WSL or a separate Ollama installation.

Allow about 100 GB free for preparation and installation, plus media and recordings. After downloading, the complete folder can be copied to USB for offline installation.

Whistle is the CPU primary for live captions. Whisper supplies fallback and recorded-media transcription, with optional supported NVIDIA acceleration.

First start or upgrade

Open CivicCast Operator Console after setup finishes. A new station creates its first administrator on that computer. For an existing station, sign in with its current administrator account; the Windows guide covers password recovery for old test accounts. Back up a working station and plan the upgrade interruption.
