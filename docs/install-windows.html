CivicCast for Windows

Current release posture: v1.0.0-beta.11 is the current release (published 2026-10-08), a GitHub pre-release. It is still a beta, not a finished production release. v1.0.0-beta.10, v1.0.0-beta.7, v1.0.0-beta.5, v1.0.0-beta.4 and v1.0.0-beta.3 (the first downloadable release) are superseded.

Download setup.exe and the runtime .ccpack packs from the v1.0.0-beta.11 GitHub Release. Verify the SHA-256 checksum against the published SHA256SUMS.txt and the Windows Authenticode signature before running the installer -- see the current release verification record for the exact install and output scope. The October 8 documentation/help revision (producer 400cff08, signed build 37857705750) passed a fresh CPU-only Windows Sandbox installation using the complete local kit and 9 GiB guest RAM. Setup took about 30 minutes, including offline model self-tests. A five-minute single-channel Whistle observation and installed Help checks passed. Repair, Beta 10 upgrade, GPU and longer capacity tests were not performed for this revision. A first install also needs the signed station folder of speech and AI models (about 21 GB), supplied in the complete kit. The setup window can download missing components, but downloading files and activating the station are separate steps; an online first install has not been proven for this exact package. Use the verified complete kit for a first install. Missing required runtime packs fail staging (exit 110); a station-activation or self-test failure is reported separately (setup exit 123, with the underlying cause in the installer log). The PDF, Word, and in-app help editions share the current manual. Chapter 10 explains the folder layout and exit codes.

Historical Beta 10 test result and private tester kits

The superseded v1.0.0-beta.10 release passed its clean-install Gate A lane (10 of 10 criteria) in Windows Sandbox on 2026-10-02. Its upgrade and download-only lanes were not run. See its historical verification record.

If Scott supplied you with a private tester kit (for example, the USB station bundle for a first-time install), use only the installer and checksum in that kit. Verify the SHA-256 checksum and the Windows Authenticode signature before running the installer. Do not substitute an installer from another build.

The Windows installer shows a visible progress heartbeat while setup is visibly active. The original October 8 package was checked in place on an existing host. The documentation/help revision was checked as a fresh installation; neither observation is a cross-version upgrade result.

Evidence boundary

Source tests, signed artifacts, and controlled Windows Sandbox checks do not establish field readiness by themselves. Physical DeckLink capture, real headend integration, and production operation remain pending until separately proven.
