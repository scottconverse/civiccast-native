CivicCast for Windows

Current release posture: v1.0.0-beta.12 is the current public GitHub pre-release, signed from source a0c98cb7. It is still a beta, not a finished production release. v1.0.0-beta.11 and v1.0.0-beta.10, v1.0.0-beta.7, v1.0.0-beta.5, v1.0.0-beta.4 and v1.0.0-beta.3 (the first downloadable release) are superseded.

Download setup.exe, all five runtime .ccpack files and the manuals from the Beta.12 release page. Keep setup and the runtime packs together. Check the published SHA-256 checksum and Windows Authenticode signature before running setup.

A first-time offline installation also needs the signed station model folder from a complete USB or LAN kit. That large folder is not included in the standard GitHub release assets. Existing installations can reuse their models. Online first-install acceptance has not been established for this package.

The Beta.11-to-Beta.12 upgrade completed in an isolated Windows Sandbox and returned a healthy service. The subsequent observation recorder did not complete; fresh-install and interrupted-repair checks were not run for this exact package. Read the verification record for the full results and limits.

If runtime packs are missing, staging stops with exit 110. Station-activation or self-test failures are reported separately as setup exit 123; consult the installer log for details. Chapter 10 of the manual explains the folder layout and exit codes.

Historical Beta 10 test result and private tester kits

The superseded v1.0.0-beta.10 release passed its clean-install Gate A lane (10 of 10 criteria) in Windows Sandbox on 2026-10-02. Its upgrade and download-only lanes were not run. See its historical verification record.

If Scott supplied you with a private tester kit (for example, the USB station bundle for a first-time install), use only the installer and checksum in that kit. Verify the SHA-256 checksum and the Windows Authenticode signature before running the installer. Do not substitute an installer from another build.

The Windows installer shows a visible progress heartbeat while setup is visibly active. Beta 11's October 8 package and 48-hour host observation are historical; see the Beta 11 verification and host reports for their limits. Beta 12's recorded normal-upgrade and recorder outcome is described above; it is not a fresh-install or repair result.

Evidence boundary

Source tests, signed artifacts, and controlled Windows Sandbox checks do not establish field readiness by themselves. Physical DeckLink capture, real headend integration, and production operation remain pending until separately proven.
