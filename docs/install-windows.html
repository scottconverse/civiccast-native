CivicCast for Windows

Current release posture: v1.0.0-beta.10 is the current release (published 2026-10-02), a GitHub pre-release ("Beta Candidate"). It is still a beta, not a finished production release. v1.0.0-beta.7, v1.0.0-beta.5, v1.0.0-beta.4 and v1.0.0-beta.3 (the first downloadable release) are superseded.

Download setup.exe and the runtime .ccpack packs from the v1.0.0-beta.10 GitHub Release. Verify the SHA-256 checksum against the published SHA256SUMS.txt and the Windows Authenticode signature before running the installer -- see the release verification record for what was and was not proven, including the Gate A lanes and the remaining acceptance boundary. A first-time install also needs the station folder of speech and AI model files (about 21 GB), which is not on the release page and is supplied in a kit by USB or network copy. The Windows setup step does not download them: with only setup.exe and the packs it stops with exit code 110 or 123. Chapter 10 of the User Manual explains the folder layout and every exit code.

Private tester kits

v1.0.0-beta.10 is a GitHub pre-release (a beta candidate), not a production release. Of the three Gate A lanes, only the clean-install lane was run for it: it passed 10 of 10 criteria, run locally in Windows Sandbox on 2026-10-02 against exactly this build. The upgrade (cross-version) lane and the download-only lane were not run; the owner waived them for this publication, so upgrading from beta.7 and a download-only install are not proven for beta.10. The human station acceptance pass has not been done, and no human field tester has signed off on it. See its verification record for what was and was not proven.

If Scott supplied you with a private tester kit (for example, the USB station bundle for a first-time install), use only the installer and checksum in that kit. Verify the SHA-256 checksum and the Windows Authenticode signature before running the installer. Do not substitute an installer from another build.

The Windows installer shows a visible progress heartbeat while setup is visibly active. Installing a newer build over an existing CivicCast installation is designed to keep operator data under C:\ProgramData\CivicCast, but upgrading was not tested for beta.10.

Evidence boundary

Source tests, signed artifacts, and controlled Windows Sandbox checks do not establish field readiness by themselves. Physical DeckLink capture, real headend integration, and production operation remain pending until separately proven.
