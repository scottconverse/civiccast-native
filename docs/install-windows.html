CivicCast for Windows

Current release posture: v1.0.0-beta.4 is the current release, a download-only upgrade for stations already on v1.0.0-beta.3 (the first downloadable release, now superseded). It is still a beta, not a finished production release.

Download setup.exe and the runtime .ccpack packs from the v1.0.0-beta.4 GitHub Release. Verify the SHA-256 checksum against the published SHA256SUMS.txt and the Windows Authenticode signature before running the installer -- see the release verification record for the Gate A run and the asset/hash/signature checks already performed. A first-time install still needs the ~21 GB AI-model bundle by USB or LAN copy -- the GitHub download alone does not include it.

Private tester kits

If Scott supplied you with a private tester kit (for example, the USB station bundle a first-time install needs), use only the installer and checksum in that kit. Verify the SHA-256 checksum and the Windows Authenticode signature before running the installer. Do not substitute an installer from another build.

The Windows installer shows a visible progress heartbeat while setup is visibly active. Installing a newer approved build over an existing CivicCast installation preserves operator data under C:\ProgramData\CivicCast.

Evidence boundary

Source tests, signed artifacts, and controlled Windows Sandbox checks do not establish field readiness by themselves. Physical DeckLink capture, real headend integration, and production operation remain pending until separately proven.
