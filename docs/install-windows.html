CivicCast for Windows

Current release posture: v1.0.0-beta.2 is the current owner-held unpublished candidate. It has no public installer asset and is not a public or production release.

There is no public Windows installer download yet. CivicCast will not publish one until the exact installer, checksum, signature, and clean-machine proof are bound to the same release candidate.

Private tester kits

If Scott supplied you with a private tester kit, use only the installer and checksum in that kit. Verify the SHA-256 checksum and the Windows Authenticode signature before running the installer. Do not substitute an installer from another build.

The Windows installer shows a visible progress heartbeat while setup is visibly active. Installing a newer approved build over an existing CivicCast installation preserves operator data under C:\ProgramData\CivicCast.

Evidence boundary

Source tests, signed artifacts, and controlled Windows Sandbox checks do not establish field readiness by themselves. Physical DeckLink capture, real headend integration, and production operation remain pending until separately proven.
