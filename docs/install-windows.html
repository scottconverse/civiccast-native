Before You Run It

Run only the rc18 release-matched installer after matching it to the supplied manifest and checksum.

Windows will show a blue “Windows protected your PC” screen the first time you run it. This is expected on a brand-new signing certificate — CivicCast is signed (verified publisher Scott Converse). Choose More info → Run anyway. See the SmartScreen walkthrough for exactly what to click and why.

Read the Windows release trust and verification guide. If a release publishes checksums or signatures for your artifact, verify the download before running it.

What The Setup Path Does

  • Guides the local Windows helper setup CivicCast needs to run meeting tools on this computer.
  • Prepares local durable storage.
  • Starts CivicCast services.
  • Hands off to the operator console.
  • Guides first-admin setup and recovery-kit creation.

What You Should Not Need

A normal operator test should not require Git, GitHub CLI, Git LFS, Python commands, Ubuntu commands, or repository source files.

When To Ask For IT Help

  • Windows does not allow administrator approval.
  • The machine blocks the Windows helper or says a required Windows setting is turned off.
  • An endpoint or SmartScreen policy blocks the signed installer from running even after "More info → Run anyway".
  • CivicCast says a required setup step needs IT help.

Uninstalling — Removing Your Station Data

When you uninstall, the uninstaller shows a “Delete the application data” checkbox. Check it to remove everything, including the ~19 GB Windows helper (the CivicCast-Ubuntu-24.04 WSL distribution that holds the database and recordings). Leave it unchecked to keep your recordings and settings for a later reinstall; the uninstaller then tells you on screen exactly what was kept.

Note two things if you keep the data: a later reinstall makes previously published recordings public again without a new approval, and a command-line silent uninstall (/S) keeps the data by default (it never shows the checkbox). To remove kept data by hand later, run wsl --unregister CivicCast-Ubuntu-24.04 and delete %USERPROFILE%\.civiccast.
