Open-source civic broadcast software - development beta

Record a meeting. Caption it offline. Publish it for residents.

CivicCast is a self-hostable, open, public-good broadcast platform for PEG and local-government stations, built to run on a Windows PC a station already owns. v1.0.0-beta.1 is a development candidate: the record-and-publish core is proven end-to-end. On-air graphics and live broadcast are new this candidate and operator-drivable. Cable headend output, multi-channel playout, and outside syndication are on the roadmap, not in this beta.

What v1.0.0-beta.1 actually does

Proven, end-to-end, this candidate.

These are exercised and verified in v1.0.0-beta.1: not a promise for a future release, and not aspirational source-tree inventory.

Record & caption

Record, then caption offline.

Record a meeting and generate captions with an on-device faster-whisper model — no cloud transcription service, no per-minute meter, no audio leaving the station's own machine.

Operator review

An audio-evidence attestation gate before anything airs.

The operator reviews captions against an audio-evidence attestation gate before a recording moves forward — a deliberate check, not a rubber stamp.

AI summary

A summary with claims linked back to the transcript.

Every AI-generated summary line links back to the moment in the transcript that supports it, so a clerk or resident can verify a claim instead of trusting it blind.

Publish

Schedule and publish with a dry-run and a dead-air warning.

Publishing to the resident portal runs a dry-run first and warns before dead air — publish is a deliberate operator action, not a silent background job.

Resident portal

Residents watch with captions, on infrastructure the station controls.

The resident portal plays published meetings back with captions attached — no third-party video platform required.

Contributor intake

Residents can submit; operators decide.

Residents submit their own recordings through contributor intake; an operator accepts a submission into an airable asset or declines it. Nothing a resident submits goes out unreviewed.

Operator manual

The manual is in the product, not a separate download.

An in-product operator manual is built into the console itself, alongside the printable PDF linked below.

Health & alerts

Honest status, not a green light that always shows green.

Health and alert surfaces report what is actually true of the station right now — a genuine problem shows as a genuine problem.

Install & upgrade

Install, and upgrade by uninstall-then-reinstall, both proven.

A fresh install and an uninstall-then-reinstall upgrade were both proven this candidate, on a real Windows box and separately in a sandboxed environment.

New this candidate

Engine-proven and operator-drivable — newer than the record-and-publish core.

These work and an operator can drive them today. They have had less real-world hardening than the core pipeline above, which is why they are called out separately rather than folded into "what works."

On-air graphics

Station bug and lower-third, operator-set.

An operator can set a lower-third and put it on air. Proven at the engine level and operator-drivable end to end. Honest limit: a lower-third change takes effect on the next pipeline build, not as a hot mid-broadcast text swap — expect a brief rebuild, not an instant on-screen edit.

Live broadcast

Live SRT ingest through the engine to HLS.

Live ingest over SRT, through the broadcast engine, out to HLS — proven this candidate with real footage, operator-drivable. Newer and less field-hardened than the recorded-meeting pipeline above.

Not in this beta

On the roadmap — do not evaluate this beta against these.

Naming these plainly is the point: a board that tests against capabilities not yet built will find gaps, and we would rather you find them here than in the console.

Roadmap

Emergency Alert System

CivicCast is explicitly not an EAS device. Do not deploy it as, or in place of, EAS/CAP alerting equipment.

Meeting night

Built around the real jobs in the room.

The admin, operator, and records clerk get tools suited to their job, connected by one pipeline so nothing has to be re-entered between roles.

01Set up

Create the first admin, save recovery information, and prepare storage on the station's own machine.

02Record

Record the meeting and generate offline captions with the on-device faster-whisper model.

03Review

Check captions against the audio-evidence attestation gate and read the transcript-linked AI summary.

04Publish

Schedule and publish to the resident portal, with a dry-run and a dead-air warning before it goes out.

05Improve

Use feedback from real meetings, and the console's own health and alert surfaces, to harden the next candidate.

3.0 master spec

Release status - development candidate

v1.0.0-beta.1 is not a public or production release.

v1.0.0-beta.1 is an owner-held native-Windows development candidate. The tag is published but carries no installer download and no download button on this page — publishing an installer is a separate, deliberate step the owner has not yet taken.

What is true right now: the record-and-publish core described above is proven end-to-end this candidate; on-air graphics and live broadcast are new and engine-proven, operator-drivable; a fresh install and an uninstall-then-reinstall upgrade were both proven on a real Windows box and separately in a sandboxed environment. Cable headend output, multi-channel playout, and outside syndication remain on the roadmap.
