Native Windows station software

Public meetings, on the air.

CivicCast is open-source software for public-access stations and small cities. It schedules your channels and keeps them on the air, records and captions your meetings, and publishes them to a portal where residents can watch. It runs on one Windows PC that you control.

Why it exists

A meeting should not need five tools to reach residents.

  • Camera recorder
  • Playout box
  • Caption service
  • Website upload
  • Schedule spreadsheet

One schedule. One library. One resident portal.

CivicCast covers the path a public meeting takes: it is scheduled, aired on a channel, recorded, captioned, checked by a person and published for residents. Staff work in one web console. Residents use a separate public portal. Live Whistle captions run on the station, with Whisper fallback scoped to the affected channel. Summary and translation use local models by default; a setup administrator can opt into Ollama Cloud or OpenRouter for those features.

What it does

The whole path from agenda to archive.

Schedule, broadcast, record, caption, publish and monitor from one staff console.

  • Schedule and air

    Three channels
    • Channels for education, government and public programming, each with its own schedule.
    • Premieres, recurring program-guide slots and auto-schedule rules that the station compiles into what airs.
    • Automatic program changes keep each channel moving through its schedule.
    • Audio leveling targets -16 LUFS for consistent listening levels.

  • Run the meeting

    Live controls
    • A live screen with pre-flight checks before a stream starts.
    • Take a live source to air from the Channels screen and return to the schedule afterwards.
    • Remote guest camera and microphone controls in configured VDO.Ninja rooms.

  • Record and collect

    Media library
    • Recurring capture schedules for live inputs and network streams, plus Record now.
    • Upload recordings, trim them, and import an agenda whose items link to times in the video.
    • Residents can submit programs through a form; staff review them in a queue.

  • Caption and review

    Local speech recognition
    • Local speech recognition makes live captions (Whistle primary, with per-channel Whisper fallback) and offline captions for recordings.
    • A person reviews and approves caption text before it attaches to a saved recording.
    • Review and approve AI summaries with transcript-time citations, then export signed records.

  • Publish to residents

    Resident portal
    • A public portal with Live now, searchable recordings, an upcoming schedule and watch pages with captions and agenda chapters.
    • A publish step with approvals, so a recording reaches residents when staff say so.
    • Works on a phone as well as a desktop.

  • Deliver and monitor

    Station health
    • Channel outputs as HLS web streams or a UDP transport stream for a cable headend.
    • A readiness screen that says whether the station is safe to broadcast, and five staff roles from setup admin to records clerk.
    • The Windows service starts and restarts the database, playout workers and caption worker for you.

Architecture

One service, a few well-known parts.

CivicCast runs as a Windows service. Its programs communicate locally, while staff and residents use their web browsers to reach the console and portal.

  • SupervisorThe CivicCast Native Supervisor service starts the other programs and restarts them if they stop.
  • Web applicationThe staff console, resident portal and documented HTTP API run on the station.
  • DatabasePostgreSQL, created and configured by the installer.
  • PlayoutOne GStreamer worker per channel, with seamless program changes and a watchdog that ends a stuck change. Outputs are HLS and UDP transport stream.
  • Captions and AIWhistle is the CPU primary for live captions; Whisper is the per-channel fallback and handles recorded-media captions, with optional NVIDIA CUDA. A local Ollama runtime provides summaries.
  • Verified installationThe installer is Authenticode-signed. Setup verifies component-pack signatures and file hashes.

Plan your station

  • One Windows PC hosts the station, staff console and resident portal.
  • CPU captioning uses Whistle, with Whisper backup and optional NVIDIA acceleration for Whisper.
  • Offline installation uses the complete kit, including the station model folder.
  • Your network and outputs determine how residents and your cable operator receive programming. The manual covers setup.

Quick start

Install it on a Windows PC.

  1. Get the kitThe Beta 19 release page carries setup.exe, five .ccpack component packs, and the signed station-model bundle. The release helper verifies and prepares the complete kit. Chapter 10 of the manual explains the folder layout.
  2. Run setup.exeWindows asks for administrator approval. Setup checks every pack, creates the database, runs a self-test and starts the CivicCast service.
  3. Open the operator consoleUse the CivicCast Operator Console shortcut on the PC, which opens http://127.0.0.1:8000/operator/. First setup only works from the station computer itself.
  4. Create the first adminChoose the station name and an admin password, and save the recovery kit. The console stays locked until you confirm it.
  5. Check ReadinessThe Readiness screen reports whether the station is safe to broadcast.

Upgrading an existing station? Back up a working station and plan the interruption. Follow the Windows installation guide for the exact release-matched kit and procedure.
