LOCAL AI, HUMAN AUTHORITY

Your meetings don't need to leave town to become accessible.

CivicCast can run speech recognition, translation, and transcript-linked summary drafting on station hardware. Operators review the work and explicitly approve publication. Cloud AI is an option - not a dependency.

  • Review queues and approval before publication
  • Summary claims trace back to transcript timestamps
  • No resident audio retained for AI training

STRAIGHT ANSWERS

Before you put it on air.

Can CivicCast run a complete PEG station?

That is the product scope, and the repository contains the workflows across playout, scheduling, production, graphics, captions, portal, archives, analytics, and reporting. The native beta still needs real station headend proof before it should be treated as field-proven for every unattended production environment.

Is the AI really local?

It can be. CivicCast supports local Faster Whisper captioning and local model workflows for summaries and translation. Optional hosted providers also exist, but the core public-meeting workflow is designed not to require them.

Is it really open source?

Yes. CivicCast code is licensed under Apache 2.0 and its documentation under CC BY 4.0. External runtimes and optional integrations retain their own licenses, and some hardware or provider accounts remain station responsibilities.

Does it replace certified EAS equipment?

No. CivicCast can ingest and display CAP/IPAWS alert content in software, but it is not an FCC Part 11 EAS device. Required EAS relay remains the responsibility of the station or cable headend.

Can we download a production installer today?

v1.0.0-beta.2 is the current owner-held unpublished candidate. No installer download is attached and it is not a public or production release. Teams can inspect and run the source now; use the repository's release record - not an old "latest" link - to determine when a verified installer is available.
