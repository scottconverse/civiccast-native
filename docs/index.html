Platform Features

Everything a modern
station needs.

CivicCast is the only open-source broadcast platform with built-in AI captioning, hardware-tier auto-detection, and full live-to-archive workflows — built for real PEG station constraints.

AI Captioning

faster-whisper with whisper-large-v3 INT8 quantization. Real-time captions that meet FCC accessibility requirements — with zero cloud dependency.

Live Streaming

Multi-output streaming to cable headend, YouTube Live, Facebook Live, and custom RTMP endpoints — simultaneously from one interface.

Hardware Detection

Run civiccast doctor to detect your GPU VRAM and assign the optimal processing tier — from iGPU to AI workstation.

Archive & VOD

Automatic recording and archival with searchable transcripts. Every broadcast becomes an accessible public record your community can reference.

Open Source

MIT licensed. No vendor lock-in, no recurring fees, no black box. Fork it, extend it, or contribute back — the way public infrastructure should work.

REST API

Full REST API including /api/hardware for tier detection. Integrate with your existing municipal systems, CMS, or automation workflows.

Hardware Requirements

Built for the hardware
you already own.

CivicCast auto-detects your GPU via civiccast doctor and unlocks features in tiers. Most PEG stations qualify for Tier 1 or better — even Tier 0 handles full broadcast workflows.

Tier 0

Integrated

<8 GB VRAM · Ryzen 7 780M iGPU

  • Live streaming
  • Schedule management
  • Basic archive & VOD
  • Manual captioning

Tier 1 — Recommended

Standard

8–16 GB VRAM · 2020-era GPU

  • All Tier 0 features
  • AI auto-captioning
  • whisper-large-v3 INT8
  • Real-time transcription

Tier 1+

Enhanced

16–24 GB VRAM

  • All Tier 1 features
  • Higher throughput
  • Multi-stream captioning
  • Extended search index

Tier 2

Professional

24 GB+ VRAM

  • All Tier 1+ features
  • RTX caption proof
  • Full-quality models
  • Multi-channel AI

Getting Started

Up and broadcasting
in three steps.

01

Download & Install

The Windows installer runs in under two minutes. No virtual machine, no WSL, no manual configuration. CivicCast installs as a native Windows application.

02

Run civiccast doctor

Hardware detection inspects your GPU, RAM, and storage, then configures CivicCast for your optimal tier. The full check completes in under 30 seconds.

03

Go Live

Connect your capture card, configure stream destinations, and broadcast. AI captioning activates automatically based on your detected hardware tier.
