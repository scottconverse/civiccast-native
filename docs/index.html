What it solves

A bounded beta workflow for recorded meetings and resident playback.

rc17's stock acceptance run (2026-07-20) covered exact-sample private rehearsal, private packaging, explicit Portal approval, and resident playback; that walkthrough has not yet been re-run on rc18's exact bytes. The broader source inventory below is not a stock acceptance claim.

PEG channel

Source inventory for integrated 24/7 operation.

Persistent GStreamer playout, three concurrent channels, query-driven auto-scheduling, the Commit-to-Air gate, and operator takeover controls.

Records

Make review part of the product.

Captions, sourced summaries, custom metadata, real RFC-3161 timestamped record exports, and a meeting-agenda sidebar synced to the video.

Reach

Give residents a stable place to watch.

Portal playback was proven in rc17's stock acceptance run (2026-07-20) and has not yet been separately re-verified on rc18's exact bytes. Podcast, Internet Archive, YouTube, and native app distribution require separate provider/store proof.

Inside CivicCast

The broader source inventory and its remaining proof boundaries.

These modules exist in the source tree and have repo evidence, but live media, hardware, headends, providers, app stores, and unattended station operation still require separate field acceptance.

Playout engine

Persistent GStreamer pipeline.

Three concurrent channels, source hot-swap without TS continuity breaks, and IP-TS / SRT / RTMP / HLS / NDI software paths. SDI/DeckLink remains config-gated and hardware proof pending through the station-supplied relay path.

Six OTT apps

Native Roku, Apple TV, Fire TV, Android TV, Android mobile, iOS.

Real platform-idiomatic starter source for all six targets that builds with each platform's own toolchain. Store-ready polish (artwork, store metadata, accessibility) is per-target follow-up.

CG bulletin board

Multi-zone rendering wired; live-video zones under contract.

Approved bulletin slides and multi-zone template rendering (primary, ticker, schedule, and logo/image zones, composited live via the GStreamer overlay leg, with a designer preview that matches what airs) are wired for production use. Live video embedded in a zone and per-channel board background audio remain contract-only until runtime proof lands (spec S15 §5).

Scheduled recording

Record from inputs or streams.

SDI / HDMI / NDI inputs or RTSP / SRT / HLS / RTMP / MPEG-TS, one-shot or weekly recurrence, arm-record-finalize state machine, an S8 (source-loss) alert on source failure.

As-run + EPG

Reporting that funders read.

As-run / proof-of-performance logs, XMLTV / X-List / CSV EPG export, franchise hours-by-category, per-underwriter affidavits, and a billing export.

Underwriting

Real PEG sponsorship trafficking.

Spot-as-asset, rotation rules, break insertion, per-underwriter affidavits via the as-run join - PEG keeps the for-profit underwriting revenue, on the rails.

Captions & EAS

Caption proofs, loudness, CAP / IPAWS display.

Local faster-whisper captions with fail-closed decode-back status, per-sink loudness target, CAP / IPAWS / NWS / AMBER display, EAS attention-tone stripping on web/OTT egress, SAP / descriptive-audio routing. The native caption runtime is built in software. Recorded-media packaging and playback were proven against rc17's exact bytes on 2026-07-20 and carry into rc18's code path; live ingest remains blocked until a server-side media probe and station egress path are separately verified.

Meeting agenda

Agenda items synced to video.

Chaptered navigation, public agenda sidebar with seek, plain-text import, optional agenda PDF beside the player.

AI choice

Operator picks the model.

Per-feature model selection across local Ollama, Ollama Cloud, and OpenRouter; defaults adapt to detected RAM. No vendor lock-in on captions, translation, or summaries.

Meeting night

Built around the real jobs in the room.

The admin, operator, clerk, and technical helper get different tools because they have different jobs. CivicCast keeps those paths connected without making everyone learn the same server vocabulary.

What it costs

One station was quoted about $48,000 for this work, plus captions by the hour. CivicCast is free.

In 2025, a Colorado PEG station received a commercial vendor's MSRP quote to refresh a single three-channel playout server, and a companion quote for captioning service. The figures below are taken directly from those quotes, which are on file with the project. CivicCast is free, open-source software doing this class of work on a Windows PC you own. It is also a controlled beta — weigh the proof boundaries above before you retire anything.

Their server

$48,537.50 for one refresh.

One three-channel playout server ($30,650), bulletin-board licenses for three channels ($4,650), extended hardware warranty ($4,597.50), and Gold support at $8,640 per year after the included first year.

Their captions

$6,700 per 1,000 hours — and hours run out.

Captioning sold as prepaid blocks: $6,700 per 1,000 hours, $3,750 per 500. Caption translation is another $3,650 per 1,000 hours. Every meeting draws the balance down; the next block costs the same.

CivicCast

$0 license. $0 per hour. Hardware you own.

Playout, scheduling, the bulletin board, and on-device Whisper captions are open source: no license fee, no per-hour caption meter, no required support subscription. The station runs on one Windows machine that costs less than a single year of that support contract.

Download the current Windows controlled beta.

A genuine clean-Windows test exposed concurrent bootstrap, Windows-servicing, and missing-progress-feedback defects in v1.0.0-rc13. It is withdrawn from beta use.

v1.0.0-rc18 is the current release. It carries rc15's clean-Windows installer repairs (validated from a WSL-disabled baseline through cold-reboot recovery), rc16's published UI/UX repairs, rc17's beta-blocker fixes, and the sixteen stage-gate fixes. Do not install rc13 — and do not use an older prerelease, a source-code ZIP, or an untagged build.

v1.0.0-rc18 is the approved installer for the controlled beta. rc18 fixes all sixteen findings a full stage gate raised against the rc17 line, three of them Critical - including a simulated archive that produced a link looking like a genuine archive.org permalink for a meeting that was never archived. Its installer is built from the gate-cleared main branch, Authenticode-signed, and proven on a genuinely clean Windows host, and its stage-gate re-run returned no blocker or critical findings. rc17 remains downloadable from its release page as the rollback target but carries all sixteen findings. rc18's proof boundary is stated at the top of its verification record.
