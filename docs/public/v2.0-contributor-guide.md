# CivicCast v2.0 Contributor Guide

Audience: community producers, partner organizations, staff contributors, and volunteers submitting media to a station.

## Submission Flow

1. Open the station's contributor submission page.
2. Provide title, description, contact information, rights/permission notes, and the media file or link requested by the station.
3. Submit the item and keep the status lookup information.
4. Watch for status updates from the station.
5. Respond if the station asks for corrected metadata, rights clarification, or a replacement file.

## Review States

- Submitted: the station has received the item.
- Needs information: the station needs a correction or clarification.
- Approved: the station accepted the item for scheduling or publication.
- Rejected: the station declined the item and should provide a reason.

## Contributor Responsibilities

- Submit only media you have permission to share.
- Do not include private personal information unless the station specifically requests it.
- Provide captions or transcript files if available.
- Keep source files until the station confirms publication or rejection.

## Station Boundaries

CivicCast provides the submission and review workflow. Editorial decisions, rights review, scheduling policy, and publication timing remain station responsibilities.
