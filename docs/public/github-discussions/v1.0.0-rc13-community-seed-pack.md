# GitHub Discussion Seed Pack: CivicCast v1.0.0-rc13

Category: Announcements

Title: CivicCast v1.0.0-rc13 Windows beta testing is paused

Body:

CivicCast `v1.0.0-rc13` is withdrawn from Windows beta installation after a
genuine clean-Windows run exposed concurrent bootstrap, Windows-servicing, and
missing-progress-feedback defects. Do not install rc13 or an earlier candidate.

The unpublished rc14 source repair serializes servicing, preserves one active bootstrap across
clicks and relaunches, and adds visible progress feedback. A replacement will
be published only after it passes a genuine clean-host install. Review the
corrected [incident record](../../releases/v1.0.0-rc13-verification.md).
