Category: Announcements

Title: CivicCast v1.0.0-rc15 Windows beta is ready for bounded testing

Body:

CivicCast `v1.0.0-rc15` was the current public Windows beta when this draft was
written (the current public beta is now `v1.0.0-rc18`):
<https://github.com/scottconverse/civiccast/releases/tag/v1.0.0-rc15>.
Do not install rc13 or substitute an older candidate, source ZIP, or untagged
build.

The exact public installer passed a genuinely clean Windows run from a
WSL-disabled baseline through Windows feature setup, dedicated Ubuntu 24.04
provisioning, first-admin setup, the recorded-media acceptance workflow,
service restart, and cold-reboot recovery. Its Authenticode signature and
Sigstore release evidence verified successfully.

The accepted stock workflow is deliberately bounded: recorded sample media,
exact-sample private rehearsal, private packaging, explicit Portal approval,
and resident playback. Live ingest, station hardware, cable/headend delivery,
external providers, app stores, and unattended operation still require
separate field proof.

One known display-state issue remains in rc15: a still-open installer can
briefly show a stale restart screen after setup is already healthy. Close and
reopen it; saved progress is retained. The fix is on `main` for the next
candidate, and the published rc15 assets have not been replaced.

Category: Q&A

Title: What should CivicCast show while Windows and Ubuntu are being prepared?

Body:

The rc15 installer keeps long-running setup visibly active. A tester should see
the current phase, step count, elapsed time, and a heartbeat that updates every
few seconds. A static screen is not considered normal.

Keep at least 5 GB free for the base installation, plus separate capacity for
recordings, media, backups, and downloaded caption models. If setup differs
from the handoff, preserve the installer log and create a redacted support
bundle. Do not share passwords, recovery codes, private meeting material,
subscriber data, or logs containing secrets.

Category: Ideas

Title: Which station proof lane should CivicCast prioritize after rc15?

Body:

Optional surfaces still require station-specific proof before they can be
described as field-proven: live ingest, Internet Archive, YouTube, email and
webhook subscribers, podcast discovery, ActivityPub federation, NAS targets,
cable headend delivery, NDI and physical video output, and streaming-TV
app-store publication.

Useful reports name the exact CivicCast release, describe the operator action,
and include only redacted evidence. Never post API keys, OAuth secrets,
passwords, recovery codes, private account details, resident data, or
unredacted logs.
