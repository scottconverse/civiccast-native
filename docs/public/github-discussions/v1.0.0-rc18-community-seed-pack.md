## Proposed body

CivicCast `v1.0.0-rc18` is the current controlled Windows beta. It is the
audit-remediation line on top of rc17: a full stage gate against the rc17 line
returned sixteen findings — three of them Critical — and rc18 fixes all
sixteen.

The three that matter most to anyone publishing a public record:

- **A simulated archive produced a receipt that looked real.** On a default
  install the Internet Archive and local-NAS targets run in simulation. The
  simulated client returned an `archive.org/details/…` link — the same shape
  the real one produces — for an item it never created, with nothing on the
  publish dashboard marking it as simulated, while the records-clerk guide
  called that archival required. A clerk could approve it, see a plausible
  archive.org link, and reasonably believe a meeting was legally archived when
  nothing had been written anywhere. The simulated target is now a
  non-resolving address, the dashboard says plainly that nothing was archived,
  and the guide says so too.
- **Anonymous uploads had no limits** — no sign-in, no size cap, no rate
  limit. They now have all three.
- **Recorded playback failed hard** whenever storage was briefly unreachable.
  It now degrades cleanly.

The other thirteen cover a station that called itself healthy with no
database, three pre-broadcast checks that had been dead placeholders since
Sprint 0.4, operator screens that showed raw machine values instead of plain
English, a publish dashboard that got slower with every meeting ever recorded,
a recording-proof test that could silently stop running in CI, a setup button
that could only fail, an endpoint that named the logged-in user, and a
first-run form that was invisible to screen readers.

**If you are running rc17, please move to rc18.** rc17 remains downloadable as
a rollback target, but it carries all sixteen of these.

Download only from the
[v1.0.0-rc18 GitHub release](https://github.com/scottconverse/civiccast/releases/tag/v1.0.0-rc18)
with its matching sidecar and complete manifest. Its exact
bytes passed a clean-host install, launch, reinstall, uninstall and rc17-to-rc18
upgrade on a pristine Windows 11 machine, and an interactive installer
walkthrough. What has and has not been proven for
this candidate is stated plainly at the top of
`docs/releases/v1.0.0-rc18-verification.md` — read it before deciding whether
this build suits your station.

Report installation results through the in-product **Report a beta issue**
link, and never include passwords, recovery codes, staff tokens, or private
meeting media in a public discussion.
