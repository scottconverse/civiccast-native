Title: CivicCast v1.0.0-rc12 is available for controlled beta testing

Body:

> **SUPERSEDED — historical.** The current published release is
> `v1.0.0-rc18` (controlled beta). This rc12 pack is retained only as a

CivicCast `v1.0.0-rc12` is a public GitHub prerelease for controlled beta
testing. Download the Windows installer and its matching release manifest,
sidecar, and Sigstore bundle from the
[rc12 release](https://github.com/scottconverse/civiccast/releases/tag/v1.0.0-rc12).

This candidate corrects a clean-Windows bootstrap issue: TSDuck could inherit a
protected Windows PATH entry and exit before first-run setup. It is a release
candidate, not production-certified station software. Review the
[verification record](../../releases/v1.0.0-rc12-verification.md) before a
station test, and use the exact assets from that release rather than a source
ZIP, an older prerelease, or detached files.

Title: New users: where does your rc12 install or rehearsal get stuck?

Body:

This thread is for people testing CivicCast without deep server or Linux
knowledge. The expected path is: download and verify rc12, run setup, create
the first admin, save the recovery kit, verify backup and restore, then run a
private first-broadcast rehearsal.

Please share the first step that was unclear, which guide you used, and safe
details such as the CivicCast version and redacted screenshots. Do not share
passwords, recovery codes, private meeting material, subscriber data, or logs
that contain secrets.

Category: Ideas

Title: Which provider or field-proof lane should CivicCast prioritize after rc12?

Body:

Several optional surfaces need station-specific proof before they can be
described as field-proven: Internet Archive, YouTube, email and webhook
subscribers, podcast discovery, ActivityPub federation, NAS targets, cable
headend delivery, NDI and physical video output, and streaming-TV app-store
publication.

Useful reports name the exact CivicCast release, describe the operator action,
and include only redacted evidence. Never post API keys, OAuth secrets,
passwords, recovery codes, private account details, resident data, or
unredacted logs.
