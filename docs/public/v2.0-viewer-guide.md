# CivicCast v2.0 Viewer Guide

Audience: residents, viewers, and community members watching live or recorded civic content.

## What Viewers Can Expect

- Live streams when the station is broadcasting.
- Recorded VOD with captions when available.
- Public schedules and now-next program information.
- Open videos without login when the station marks them public.
- Restricted videos only when the station has granted access.
- Searchable or browsable station content where the station has enabled it.

## Captions And Transcripts

Captions may be produced locally or imported from an external caption appliance. Operators review caption output before publication where review is required.

## Privacy

CivicCast is designed for public-interest media and public-record workflows. Viewer analytics and subscriber features should be configured according to the station's privacy policy. Do not send private credentials or sensitive personal information through public feedback channels.

## Access Problems

If a video is unavailable, gated, or missing captions, contact the station using its published support channel. Include the event title, date, page URL, and what device or browser you used.
