2. **Mutation child harness.** The pytester child now imports the actual

   The new application-import tripwire failed with the original whole-conftest

   rejected by the real guard at teardown. Full file: 7 passed. Details and
   exact red/green commands are in `harness-receipt.md`. No local mutation-score
   substitute was run; the actual Linux mutation lane remains pending CI.

3. **Windows launcher normalization.** This is a real execution defect, not
   merely a raw-byte assertion problem. uv reads the interpreter through PE
   resources, but Python selects the script from a ZIP inside the complete EXE.
   With uv 0.12.13, UpdateResourceW alone can retain the old ZIP after replacing
   the active resources. The old script can then win ZIP selection. The repair
   validates the original and new ZIPs, clears only complete old payload copies
   outside the uniquely identified active payload, preserves the file length,
   and verifies both PE resources plus the script selected from the whole file.
   It rejects malformed or ambiguous state and preserves repeat normalization.
   It does not globally replace interpreter-path strings; an obsolete path in
   PE slack is not treated as an active interpreter choice.

   `launcher-matrix.txt` reproduces the defect using the pushed builder and
   actual launchers generated by isolated official uv 0.12.12 and 0.12.13.
   The old normalizer passes on uv 0.12.12. On uv 0.12.13 it reports the new active
   resources but selects the old script and exits 1 before the benign fixture.
   The corrected normalizer executes the benign replacement twice for each uv
   version through the relocated `runtime\python.exe`, with bytecode disabled
   and no fixture `.pyc`. It leaves the source launchers unchanged. These are
   small isolated executable fixtures using ordinary Python 3.12.10 and its
   standard library, not an assembled CivicCast candidate or installer test.

The upstream loading contract is visible in
[uv 0.12.13 trampoline builder](https://github.com/astral-sh/uv/blob/0.12.13/crates/uv-trampoline-builder/src/lib.rs#L42-L51).
The first hypothesis that retained bytes were inert was disproved by execution
and was not used for acceptance.
