## How To Read This

Every subsystem is classified with one or more of these states. The distinction between **proof** and **production** is deliberate and load-bearing: "real proof" is **not** "production lifecycle."

| State | Meaning |
|---|---|
| `mock only` | Returns fabricated success; no real network/IO. |
| `real component` | Real, correct code in isolation. |
| `real proof` | Real code with a CI/proof path exercising it end-to-end at a declared `proof_boundary`. |
| `implemented but not wired` | Real component that nothing in the product invokes. |
| `production-wired` | Invoked by the real product workflow. |
| `production-supervised component` | Supervision behavior (start/health/restart/stop) exists in code and is proof-validated, but not a deployed operational lifecycle. |
| `missing` | Not implemented; no runtime code. |
| `deferred` | Explicitly out of scope or placeholder. |

An `A -> B` entry means the component is `A` but its current limitation is `B`, such as real code that is not durably stored.

## Proof Is Not Production

CivicCast's broadcast/streaming core is real: egress, CDN adapters, ActivityPub signed delivery, and cable file-package output. The v0.1.0-rc6 public-beta line has clean Windows, release-artifact, and local public-beta soak evidence, but LPM headend/device proof remains a station-device rung. The local 3.2 contract-lab work is not release evidence until its static gates, dependency-host gates, vMix software-lab proof, clean first-run evidence, elapsed soak, and station-device evidence are attached. Real adapters now exist for Internet Archive, YouTube, SMTP mail, subscriber webhooks, and the local-NAS archive copy but stay behind explicit config (`CIVICAST_PROVIDER_*=real`); the default publishing/provider delivery surface remains simulated.

Keep these states distinct when updating this file. A subsystem moving from `real proof` to `production-supervised component` to a deployed lifecycle is a real promotion that should be reflected here explicitly, not implied by prose elsewhere.
